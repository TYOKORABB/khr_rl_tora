卒論の研究で使ったプログラムを、ゼミや発表で説明できるようにまとめた資料です（2026-11-27 作成）。
重要な部分は、コードを引用して 1 行ずつ解説しています。

- 引用と行番号は、コミット `1b395b1` の時点のファイルから `docs/tools/make_code_guide.py` が取り出しています。手で写したものではありません。
- コードを変えたら `python docs/tools/make_code_guide.py --strict` で作り直してください。行がずれて解説の抜けが出たら、警告で分かります。
- 解説の本文は `docs/CodeGuide/_spec/*.txt` にあります。直すときはこちらを直して、作り直してください（`.md` を直接直すと、次に作り直したときに消えます）。

## 使う言葉と記号

| 言葉 | 意味 | コードでの名前 |
|---|---|---|
| 方策 | 観測を入れると行動を出すニューラルネットワーク（MLP）。学習で作るもの | `actor`、`policy` |
| 価値関数 | 状態のよさ（この先にもらえる報酬の合計の見込み）を出すネットワーク。学習のときだけ使う | `critic` |
| 観測 | 方策に入れる数の並び。実機でも測れる量だけを使う | `obs_buf`（`"policy"` の組） |
| 特権観測 | 価値関数にだけ入れる、シミュでしか分からない量（摩擦・質量・胴体の速度など） | `privileged_obs_buf` |
| 行動 | 方策の出力。22 関節ぶんの数 | `actions` |
| 公称姿勢 | 四脚で立っている基準の関節角。歩行の初期姿勢で、起き上がりのゴール | `default_joint_angles`、`NOMINAL_QUAD`、`q_nom` |
| 目標角 | サーボ（シミュでは PD 制御）に送る角度 | `target_dof_pos`、`q_cmd`、`target` |
| 比例ゲイン・微分ゲイン | PD 制御の係数。力 ≈ kp ×（目標角 − 角度）− kd × 角速度 | `kp`、`kd` |
| base 座標 | 胴体（base_link）に固定した座標。x が胸の向き（四脚の姿勢で真下）、y が左、z が頭の側 | `base_*` |
| loco 座標 | 公称姿勢のときに世界の座標と重なる座標。前進・横・旋回はこれで測る | `loco_*` |
| u | 重力の向きの base の x 成分。四脚・うつ伏せで +1、仰向けで −1。起き上がりで「どれだけ胸が下か」に使う | `u`、`down[0]` |
| 個体差（ドメインランダム化） | 摩擦・質量・重心・サーボの 0 点のずれなどを、体ごとに乱数で変えて学習すること | `randomize_*`、`dr` |
| 周期・ステップ | 方策が 1 回動く間隔。20 ms（50 Hz） | `dt = 0.02` |
| エピソード | 1 体が初期状態から終わり（時間切れ・転倒）までに動く 1 回分 | `episode_length_buf` |
| イテレーション | 学習の 1 回の更新。4096 体 × 24 周期ぶんを集めて、方策と価値関数を直す | `max_iterations` |
| Meridim90 | PC と機体の ESP32 がやりとりする 90 個の整数の並び（100 Hz） | `m`、`meridim` |
