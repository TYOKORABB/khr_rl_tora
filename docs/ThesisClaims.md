- 元にしたもの: `docs/ResearchPlan.md` §3（10/14 の相談材料）。そのあとに出た結果（是正後の報酬の総点検、起き上がりの比較）と、文献の簡単な確認を足した。
- 数値は、元の機械可読のファイル（`experiments/results_json/`・`results_json_fixurdf/`・`ablation_v31/results.json`・`real/20261013_walk/analysis.json`・学習時の `cfgs.pkl`）から

## 2. 候補ごとの証拠（是正後）

### A. トルクの制約

| 証拠 | 数値（是正後・3 seed） | 強さ |
|---|---|---|
| 全版の比較: トルクを罰する報酬を入れた v9 で一段下がる | トルク平均 32.8 → 19.5 %（−48.8σ）、99%点 100 → 72.1 %（−32.7σ）。v10 で 99%点 54.8 %（v9 から −20.2σ）。v2〜v8 は 3 seed とも 99%点 100 % | 強い |
| **是正後の総点検（10/23 に 3 seed がそろった）**: `torque_limits` を外す | 99%点 58.1 → 100 %（3 seed とも）、90 %超の時間 0.0001 → 55.9 %、トルク平均 18.9 → 72.7 %。代わりに前進は 0.233 → 0.274 m/s、足上げは前 19.6 → 27.4 mm・後 17.8 → 36.2 mm と大きくなる | 強い（是正前の 8 月の ablation を是正後の機体で再現した） |
| 重みを強めた v30 → v31 | 99%点 61.5 → 58.1 %（−4.0σ）、トルク平均 19.7 → 18.9 %（−2.7σ） | 中 |
| ほかの項目を外すと最大トルクに達する | `joint_torques`（seed 3 が 100 %）、`knee_swing_flexion`（seed 3 が 100 %） | 補足 |
| 実機 | v31-s2 で 108 秒、サーボのエラー 0（68,178 パケット）、転倒 0 | 中（発熱・電流は測っていない） |

弱いところ:

- **方法そのものは新しくない。** 四脚ロボットの学習で広く使われる legged_gym（Rudin ら、CoRL 2021）に、同じ考え方の報酬 `_reward_torque_limits`（上限の一定割合を超えた分を罰する）がある。
  本研究の形は「最大トルクの 60 % を超えた分の二乗」。言えるのは「この方法が、最大トルクの小さいホビー用サーボの機体で効くことを、全版の比較・是正後の ablation・実機で定量で示した」まで。
- **実機の発熱・電流を測っていない**（研究計画書 Phase 1-4）。
- **基準のトルクの電圧**: 1.373 N·m は 11.1 V 時。標準のバッテリーは 9.9 V なので、電圧に比例すると仮定すると最大トルクは約 1.22 N·m（起き上がり計画書 F10）。
  この基準で読み直すと v31 の 99%点 58.1 % は約 65 % になる。実機の電源電圧を測って基準を決める必要がある。

### B. 二足機の四脚化と実機転移

| 証拠 | 数値・内容 | 強さ |
|---|---|---|
| 四脚の形 | 腕 = 前脚、胴体を y 軸まわりに +90°、全 22 関節を制御、対角の 2 本ずつのトロット（周期 0.5 秒） | — |
| 座標系の補正（loco frame） | 報酬は世界にそろえた座標で、観測は胴体の座標のまま。胴体の座標で測ると旋回が −4 % と誤って出た | 工夫として書ける |
| シミュレーションの性能（v31、個体差あり・128 体） | 前進 0.233 m/s（指令 0.3 の 78 %）、後退 88 %、左横 70 %、左旋回 101 %、右旋回 100 %、全方向で転倒 0、トルク 99%点 50〜58 % | 強い |
| 実機（10/13） | 108 秒・転倒 0・安全装置の停止 0・全方向。歩容の周期は 2.00 Hz で学習環境と同じ。旋回は指令の 88 %（学習環境 103 %）、関節のずれ最大 10.9° | 中〜強（1 体・1 日・5 回） |
| 学習環境とのずれの分析 | 胴体の傾きの一定のずれ（横 +2°・前後 −2〜−3°）、旋回の遅れ（行動の遅れ約 +20 ms で再現）。観測の作り方は学習時と 1e-6 以内で一致 | 中（同定ではない） |
| 四脚で初めて露出したモデルの誤り | 右股関節ピッチの可動域が左と鏡像。二足では余裕があり影響しなかった。全 29 版を学習し直した | 経緯として強い |

弱いところ:

- **「なぜ四脚か」に答える比較がない**（二足との比較、研究計画書 Phase 3-8）。
- **実機の速さを外から測っていない**。実機の試行は 1 体・1 日・合計 108 秒。
- **前脚（腕）の弱さ**: 歩容の一致は前脚 85.9 ± 3.8 %、後脚 88.1 ± 1.0 %（v31）。横移動は 70 %。
- **先行研究との差は未確認**。10/23 の簡単な検索では、ヒューマノイドが腕を前脚にして四脚で歩く方策を強化学習で得た例は見つからなかった
  （iCub は這い歩きを前提に設計されたが、強化学習ではない）。新しさとして書くなら、きちんとした文献調査が要る。

### C. 報酬の設計則

| 証拠 | 数値（是正後・3 seed） | 強さ |
|---|---|---|
| 膝: 絶対角度 → 接地時の膝角度からの差分（v16 → v17） | 膝の可動範囲 3.4 → 48.9°（+7.9σ） | 強い |
| **是正後の総点検**: `knee_swing_flexion` を外す | 膝の可動範囲 29.3 → 5.8°（3 seed とも 5.5〜6.3°）、後脚の足上げ 17.8 → 9.0 mm、seed 3 でトルク 100 % | 強い（是正前の結果を再現） |
| **是正後の総点検**: `feet_clearance` を外す | 足上げ 前 19.6 → 14.9 mm、後 17.8 → 12.7 mm | 中（項目が要ることは言えるが、「相対量」が要ることの確かめにはならない） |
| 観測できること: v23 → v24 → v25（罰だけ → 罰と観測） | 横ずれ 9.0 → 10.9 → 2.2 %（v24 → v25 で −3.9σ）。v25〜v29 の 15 本すべて 4.3 % 以下 | 強い（事前の予測が当たった） |
| 適用条件: v25 → v26 → v27（着地の足裏） | 4.4 → 5.8°（+2.9σ、失敗）→ 3.8°（−4.1σ） | 中 |
| 足裏の向き: v17 → v18 | 着地の足裏 17.9 → 4.7°（−26.5σ） | 強い |

弱いところ:

- **「相対量」の対照実験（クリアランスを絶対の高さに戻す、前脚の足上げ −4.8σ）は是正前の機体だけ**。是正後には測り直していない（3 seed、GPU で約 3 時間）。
- **是正後の総点検で、読み方に注意が要る結果が出た**（`experiments/ablation_v31/findings.md`）:
  - `feet_orientation` を外すと、着地の足裏の傾きが seed 1・2 で 41.3°・31.3° に崩れ、seed 3 は 5.6°（基準 4.4 ± 0.3°）。学習の前に決めた基準では「削除可」（比べる幅に外した構成の seed 間のばらつきを入れるため、seed で割れると悪化と判定されない）。
    是正前の「30σ で必須」とは言い方が変わる。「3 seed のうち 2 本で崩れる」と書くのが正確。
  - `heading_error`（累積ヘディング誤差の罰）を外しても、横ずれは 2.5 → 5.9 %（3 seed とも悪い側）でノイズ床の 2σ（4.4 %）の中。基準では「削除可」。
    観測（v25 で足した累積ヘディング誤差の観測）は残したままなので、「観測があれば罰は弱くてもよい」可能性があるが、この結果だけでは言えない。
- **一般化の範囲**: 1 つの機体・1 つの課題から得た則。相対量の報酬（接地時からの足上げなど）や、観測できない量を罰しても効かないことは、強化学習の一般論としては知られた考え方に近い。
  「新しい則」ではなく「事例と対照実験で確かめた設計の指針」として書くのが安全。

## 5. おすすめ（Claude の意見）

**案 1（B を枠、A・C を中身）**。理由:

1. テーマ（二足歩行ロボットにおける四脚歩行）にいちばん忠実で、実機で歩いたという、ほかの案にない結果が中心に来る。
2. A と C の中心の証拠（トルク、膝）は、是正後の総点検で 3 seed とも再現した。是正前の結果に頼らずに書ける。
3. A だけ・C だけを軸にすると、新しさの弱さ（A は既存の方法、C は一般論に近い）がそのまま論文の弱さになる。案 1 では「この機体で何が効き、何が効かなかったか」を定量で示す形になり、弱さが目立たない。

案 1 で残る弱点は「なぜ四脚か」。手当ては 2 通り:

- 書き方で答える: 二足より支持点が多く転びにくい、低い所を通れる、二足用のハードを使い回せる、という動機を、文献（四脚での這い歩きを前提にした人型の設計など）とともに序論に書く。追加の実験なし。
- 小さな比較をする: 二足の基準（`biped/`、先輩のサンプル）を同じ測り方（押しへの強さ・トルク）で 3 seed 測る。測定の道具を二足に合わせる作業と、学習 3 本（約 3 時間）が要る。

どちらにするかは教授と決める（下の 1・2）。

## 8. 10/14 の相談材料（研究計画書 §3）から変わったこと

- 是正後の総点検（57 本のうち 53 本の学習が済んだ時点、10/23 21 時）で、A の `torque_limits` と C の `knee_swing_flexion` が是正後も必須と分かった（研究計画書 §3 の「是正後には測り直していない」の注が外せる）。

- A の「定格 1.373 Nm」は「最大トルク 1.373 N·m（11.1 V 時）」に直す。電源電圧の問題がある。
- A の方法（トルクの上限に近い分を罰する報酬）は legged_gym に既にある。新しさの書き方を変える。
- 起き上がり: 先輩の方法を本研究の条件に近づけると立てなくなり、遅れ・制限・写像のどれか 1 つを先輩の側に戻すと立つ（`getup/DIARY.md`）。入れるなら A（実機のサーボの制約）の話としてつながる。
