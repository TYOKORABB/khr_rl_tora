## 3. 【教授への相談材料】研究の「売り」の候補

テーマは「二足歩行ロボットにおける四脚歩行」。主張の置き方に3案あり、**既に手元にある証拠**と
**追加で必要な実験**を対にして示す。3案は排他ではなく、**B を全体の枠、A・C をその中身**にする
構成も可能（むしろ自然）。**数値は、断りがなければ是正後の 3 seed**。

### 候補A: 低トルクサーボ機における「トルク制約を明示した報酬設計」
- **主張**: 定格 1.373 Nm という厳しい制約下で、飽和させずに歩かせる報酬設計を確立した。
- **手持ちの証拠**:
  - **是正後の全版の比較で、トルクを罰する報酬を入れた v9 でトルクが一段下がる**（平均 32.8 → 19.5 %・−48.8σ、99%点 100 → 72 %・−32.7σ）。
    v10 で 99%点 55 %（−20σ）、以後 52〜66 %。v1〜v8 は 3 seed とも 99%点 100 %（常にどこかが飽和）。
  - **ablation で `torque_limits` が必須と実証**（外すと 90%超の時間 0.00 → 11.17%、99%点 59.7 → 100%。是正前の機体）。
  - v31 で `torque_limits` を強めると、v30 よりトルク平均 −2.7σ・99%点 −4.0σ（是正後）。v31 は 99%点 58 %・90%超の時間 0.0001 %。
  - 実機で発熱・脱調なく 62 秒（v19、8/10）、**v31 で 108 秒・サーボのエラー 0**（10/13）。
- **追加で必要**: 実機での発熱・電流の実測（Phase 1-4）。
- **強み**: この機体固有の制約に正面から答えており、実機で実証済み。**是正後の全版の比較と ablation の両方の裏付けがある。**

### 候補B: 二足ヒューマノイドの四足化と実機転移
- **主張**: 二足用ハード（KHR-3HV, 22関節）を四足として使い、RL で歩行を獲得し実機転移した。
- **手持ちの証拠**:
  - 腕＝前脚・胴体90°ピッチという形態設計、**loco frame 補正**という技術的工夫
  - **v31 の実機歩行（108 秒・転倒 0・前後左右と旋回）**、v19 の 62 秒
  - 学習環境とのずれの定量（旋回 88 % 対 103 %、胴体の傾きの一定のずれ、関節のずれ 1〜2°）と、その原因の候補（IMU の取り付けの誤差・遅れ）
  - **四脚化で初めて露出した URDF のバグ**の発見と是正（二足では可動域に余裕があり影響しなかった）
  - 腕を前脚にする形の弱点の定量（歩容の一致が前脚 83 % 対 後脚 88 %）
- **追加で必要**: **先輩の二足との比較実験**（Phase 3-8）。「なぜ四足か」に答えるため。実機の速さの外部計測。
- **強み**: 提示されたテーマに最も忠実。ただし比較が無いと「なぜ四足か」に答えられない。

### 候補C: 報酬設計の設計則 — **最も証拠が厚い**

- **主張**: 望む結果は、**その部位自身の基準からの相対量**で、**望む局面で**測って報酬化すべきであり、
  さらに **罰する量は方策が観測できなければならない**。この設計則を、成功例・失敗例・
  統制された ablation・対照実験の4種類の証拠から導き、**URDF 是正後の全版の再学習でも確かめた**。

#### 手持ちの証拠（5 層）

**① 設計則の適用事例（成功と失敗の対）**

| 版 | 誤り | 修正 | 結果（当時） | 是正後の 3 seed |
|---|---|---|---|---|
| v13 | クリアランスを**絶対高さ**で測っていた | 接地基準からの**相対量**へ | 前脚クリアランス3倍 | （足上げは標準の測定にない。ablation ② で確認） |
| v16 | 膝の**絶対角度**を報酬化 | **swing−stance の差分**へ（v17） | 報酬ハック（ROM 2.7°）→ 解消（56°） | 膝 ROM 3.4 → 48.9°（+7.9σ）で再現 |
| v24 | 直進性を **yaw 角速度（率）** で測っていた | **累積量**へ、かつ**観測にも入れる**（v25） | 横ずれ 8.08 → 2.88 % | **10.9 → 2.2 %（−3.9σ）。v25〜v29 の 15 本すべて 4.3 % 以下** |
| v25 | 足裏水平を**接地期全体**で測っていた | 蹴り出しを外す（v26、失敗）→ 着地の直前から求める（v27） | 着地時 5.80 → 8.80（v26）→ 4.41 °（v27） | v25 4.4 → v26 5.8（+2.9σ）→ v27 3.8 °（−4.1σ）で再現 |

> **外した事例**: v21 → v22（対称性をトルク差ではなく接地時間の差で測る、接地率左右差 14.0 → 2.2 pt）は、
> 設計則としては筋が通るが、**改善そのものがノイズだった**（seed study・ablation・是正後の 3 seed のいずれでも差がない）。事例には使わない。

**② 統制された ablation（設計則そのものの検証、8/21、是正前の機体）**

`feet_clearance` の**形だけ**を v1〜v12 の絶対高さ版に差し戻し、他はすべて v23 と同一にして 3 seed 学習した。

| 指標（個体差あり） | baseline (4seed) | 2σ | ablation (3seed) |
|---|---|---|---|
| **前脚の足上げ量** | 0.0191 ± 0.0009 m | 0.0018 | **0.0149 ± 0.0009 m（4.8σ 低下）** |
| 後脚の足上げ量 | 0.0183 ± 0.0039 m | 0.0077 | 0.0172 ± 0.0037 m（変化なし） |

**「前脚だけ」が下がったことが診断の正しさを裏づける。** v13 の診断は「前脚は立位で既に目標 0.06 m を
超えており、上げるほど報酬が減る＝足上げを罰する。後脚にはその構造がない」だった。
相対化で報酬が単に強くなっただけなら**前後とも下がるはず**である。
さらに ablation の前脚 14.9 mm は、**v12 当時に実測された「すり足 0〜14 mm」とも整合する。**

**③ 対照実験 v23 → v24 → v25（報酬を変えず「観測できるか」だけを変えた）**

| | 累積ヘディング誤差を**罰する** | 累積ヘディング誤差を**観測できる** | 横ずれ（当時、個体差あり） | 横ずれ（是正後、3 seed） |
|---|---|---|---|---|
| v23 | ✗ | ✗ | 8.08 % | 9.0 % |
| v24 | ✓ | ✗ | **12.18 %**（改善しない） | 10.9 % |
| **v25** | ✓ | **✓** | **2.88 %** | **2.2 %** |

**v24 は失敗版ではなく、「罰するだけでは足りない」ことを示す対照条件**である。
根拠となる数値: 個体差が生む yaw バイアス ≈0.022 rad/s に対し観測 `ang_vel` のノイズは ±0.4 rad/s
（**S/N ≈ 1/18**）。記憶を持たない MLP 方策は自分の旋回バイアスを**原理的に検出できない**。
漏れ積分（τ≈10 s）がローパスとして働きノイズを √500 ≈ 22 倍平均化することで可観測になる。
→ **報酬設計の則を観測設計の則へ一般化できた。** そして**是正後の機体・15 本でも崩れなかった**（本書の中でいちばん強い証拠）。

**④ 適用条件の発見（v26 の失敗）**

罰 `tilt²` の配分を測ると **7 割が蹴り出し期**に費やされ、着地には 1 割しか掛かっていなかった。
この測定は正しかったが、そこから「蹴り出しの罰を外せば着地に集中する」と推論したのが誤りで、
**着地時の傾きは 5.80° → 8.80° と悪化し、トルクピークは 3 seed 中 2 seed で 99% 超**（要件違反）。
蹴り出しの拘束が**着地の足裏姿勢を間接的に規定していた**。

> **「罰がどこに掛かっているか（量の配分）」と「罰がどこで効いているか（因果）」は別である。**
> 設計則の**素朴な適用が失敗した例**＝**適用条件の発見**として記録している。

**⑤ 報酬の総点検（v28）が示したこと**

- **罰は効いているほど自分の値が 0 に近づく**（v24 → v25 で `heading_error` の寄与は 1/9）。寄与の小ささでは不要と言えず、外して学習し直すしかない。
- 27 項目のうち 9 項目は外しても劣化しない。一方、外すと崩れる報酬を特定した（`feet_orientation`・`torque_limits`・`knee_swing_flexion`・相対の `feet_clearance`・`tracking_lin_vel`）。
- **当時は「外したら横ずれ・速度・横移動が良くなった（報酬を足すことには見えないコストがある）」としたが、是正後の 3 seed では横ずれ・速度は再現しない**。
  横移動だけは是正後も 68 → 75 % と上がった（10/14、`experiments/retrain_fixurdf/strafe_after_fix.md`）。主張は「劣化しない＋横移動は上がる」。

> **注（ablation と総点検の機体）**: ②と⑤、8 月の ablation は URDF のバグがあった機体で行った。v15 以降の方策は股関節が可動域の端に触れる時間が 4〜12 % で、
> バグは制約としてほとんど効いていなかったため、**「必須か不要か」の判定は是正後もおおむね有効**と考えている。ただし是正後には測り直していない。

#### なぜこれが強いか

1. **予測力**: v24→v25 と v27 は、設計則から**事前に**対策を導き、その予測が 2σ を超えて的中した。**是正後の再学習でも同じ向き・2σ 超で再現した**。
2. **統計的裏付け**: ablation で 4.8σ・膝 ROM 33.9→6.6° といった大きな効果を検出している。
3. **反例も持っている**: `contact_duty_balance` は**効果なし**と判明し、v22 の「改善」も事例から外した。
   「効いたものだけ並べる」のではなく**否定した設計・撤回した結論も記録**している。
4. **適用条件まで示している**: v26 の失敗により、設計則が万能でないことと、その境界を示せる。
5. **方法論そのものが資産**: 「ノイズ床を測ってから 2σ で判定する」運用、「学習 seed と測定 seed のばらつきを分離する」分析、
   **モデルのバグを見つけて全版を学習し直し、どの結論が残るかを確かめた**こと。学生研究では珍しい強み。

- **追加で必要**: なし（証拠は揃っている）。ablation を是正後の機体で 1〜2 本測り直せれば、②⑤の注が外せる。
