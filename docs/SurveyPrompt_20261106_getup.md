# 1. 背景（私の研究の現状）

- 対象: 近藤科学の小型人型ロボット KHR-3HV。サーボは KRS-2552RHV ICS（22 個、仕様のトルク 14.0 kgf·cm @11.1 V、
  取扱説明書の最大電流 1.3 A @11.1 V）。制御基板は ESP32（Meridian）、PC から UDP で 50 Hz、各関節に目標角（位置指令）を送る。
  電源は研究室で共用の AC アダプター 12 V・5 A（60 W）。安定化電源は無い。サーボの電流・電圧はまだ測っていない。
- 研究: 腕を前脚にした四脚歩行を強化学習で獲得させ、実機で歩かせた（同じ AC アダプターで 108 秒歩けた）。
  いまは「転んだ状態（うつ伏せ・横倒しなど）から四脚の立ち姿勢へ起き上がる」動作を学習し、実機に移そうとしている。
- 学習: シミュレータ Genesis 0.4.6、PPO（rsl-rl）、4096 体を並列、関節は PD（kp 25 N·m/rad、kd 0.5）、トルクの上限は仕様の 90 %。
  送る目標角は「測った角度 ± 0.05 rad」に収める。個体差のランダム化（摩擦・質量・重心・0 点のずれ・IMU の傾き）あり。
- 実機の結果（11/6）: うつ伏せから 4 回試し、4 回とも起き上がれなかった。胸は腕で持ち上がるが、肩と肘が目標角の上限いっぱいで
  押し続けたまま回りきらない。同じ始めの姿勢は、シミュでは 64 回中 64 回成功する。
  シミュで「関節ごとのトルクの上限を仕様の 30 % にする」と実機と同じ形の失敗になる。硬さ kp を下げるだけでは胸が上がらず、実機と合わない。
- 原因の候補: (a) 電源の電流の合計の不足（22 個が同時に強く押すと 5 A を超える見込み）、
  (b) サーボの設定（ICS のストレッチ・電流制限・パンチ）や電圧低下で、1 個ずつが出せるトルクが仕様より低い、(c) シミュの接触・形状の違い。
- 対策として、弱さ（関節ごとのトルクの上限の倍率 0.3〜1.0、電源の合計の上限）をランダム化して学習を続けた。
  シミュでは弱い条件でも 93〜98 % 起き上がるようになったが、(1) 元の強さで広い姿勢から試すと成功が 97〜99 % → 81〜87 % に下がった（忘却）、
  (2) トルクから電流を見積もると元の強さで平均 8.6 A（5 A を超える）。立って止まったあとも、方策が目標角を周期ごとに細かく動かすため電流が下がらない、
  (3) 同じ見積もりの式で四脚歩行も 6.4 A になるのに実機は歩けたので、電流の見積もりの式が多めの可能性がある。

# 2. 調べたいこと（優先の高い順）

Q1. 人型ロボットの起き上がり（転倒からの復帰）を強化学習で学習し、実機に移した研究。特に小型・サーボ駆動の機体。
    何が Sim2Real の決め手だったか（アクチュエータの模型・同定、ランダム化の範囲、トルクの上限、動きの速さを落とす、報酬・正則化、
    実機の成功率と試行回数、失敗の原因）。
Q2. 小型サーボ（近藤 KRS、Robotis Dynamixel、ホビーサーボ）のアクチュエータの模型と同定。
    トルク・速度・電流・電圧の関係、サーボ内部の位置制御（P ゲイン、デッドバンド、電流制限）、電圧低下・電池の残量の影響、
    同定のやり方（重りを下げる試験、トルク・速度曲線、アクチュエータネットワーク）。シミュの PD をサーボに合わせる方法。
Q3. 電源・電流・消費電力の制約を学習に入れた研究。電流や電気的な仕事率の罰、電源の上限の模型、電池の電圧の模型、
    消費電力を減らす報酬が Sim2Real に効いた例。
Q4. 力の不足への頑健化と忘却。モーターの強さのランダム化（motor strength randomization）の範囲と効果、カリキュラム、
    学習済みの方策を新しい条件で学習し直すときに元の条件の性能を保つ方法（元の条件を混ぜる、蒸留、正則化など）。
Q5. 行動の滑らかさと消費電力・Sim2Real の関係。行動の変化の罰（action rate）、低域通過フィルタ、Lipschitz の制約、
    CAPS などの滑らかさの正則化が、電流・発熱・実機の成功に効いた例。
Q6. 実機で測る方法。KRS サーボ（ICS 3.5・3.6）で電流・温度・電圧を読み出せるか（コマンドと分解能）、
    KRS-2552RHV ICS の無負荷電流・停動電流・電流制限の既定値、ストレッチ・パンチの意味。電源とロボットの間で電流を測る安い方法。
Q7. 日本の先行研究。KHR シリーズや小型人型ロボットの起き上がり動作・強化学習（J-STAGE の日本ロボット学会・ROBOMECH・
    日本機械学会、CiNii Research、大学の卒論・修論の公開ページ）。
