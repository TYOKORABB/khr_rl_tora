# 卒業論文の章立ての骨組み（案、2026-10-21）

ユーザーの依頼「進めれることは全部進めて」（10/21）で作った、執筆を始めるための骨組み。**主張は 10/23 にユーザーが「いったん B を枠、A と C を中身」と決めた**（教授への確認はこれから、`docs/ThesisClaims.md`）。
卒論の本文の章立ては、この表ではなくテンプレートに従う（`../soturon_ban/`、v2 から）。起き上がり（第 8 章）は 10/23 のユーザーの決定でいったん保留。
ここでは研究計画書で「自然」とした形、**B（二足ヒューマノイドの四脚化と実機転移）を全体の枠にして、A（トルクの制約）と C（報酬の設計則）を中身にする**形で組んだ。
主張が変わっても、章の材料はほぼそのまま使える（順番と重みが変わる）。

- 数値はすべて URDF 是正後の 3 seed（`docs/DevelopmentDiary_v2.md` の「数値には 3 つの世代がある」の C）。当時の値は経緯として書く。
- 状態の印: ✅ 材料がそろっている、🟡 自動実行中か予定が決まっている、⬜ まだ無い（やるかどうかを含めて未決定）。
- 起き上がり（第 8 章）は 12/11 に入れるかを判断する（計画書）。入れないときは第 9 章の「今後」に移す。
