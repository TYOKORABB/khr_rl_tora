# sysid/ — 実機の記録と学習環境を突き合わせる（同定の下準備）

`GetUpSim2RealPlan.md` §4.1・§5.3。実行はリポジトリのルートから `python -m sysid.<名前>`（Genesis は CPU）。結果は `experiments/sysid/`。

| ファイル | 内容 |
|---|---|
| `closed_loop.py` | 学習環境で四脚歩行の方策を、`real/walk_session.py` と同じ観測の作り方で何体も同時に動かす。体ごとに摩擦・質量・重心・関節の 0 点のずれ・IMU の取り付け誤差・行動の遅れ・関節の符号の反転を変えられる（PD ゲインとトルク上限は全体で 1 つ） |
| `walk_sweep.py` | 実機歩行と同じ指令の列で条件を 1 つずつ・組み合わせで変え、実機とのずれ（傾き・旋回の比・関節の追従・可動域の端）の残差を出す（`run` → `report`） |
| `sim_replay.py` | E4a: 実機の記録を 1 秒ずつに切り、各区間を実機の状態から始めて実際に送った目標角で動かす（開ループ）。区間ごとの関節角と胴体の傾きの誤差を保存し、物理を変えた版（M1）と同じ区間で比べられる |

注意: Genesis の接触の摩擦は max(床, 機体) なので、`closed_loop`・`sim_replay` は床を 0.01 にして機体側で摩擦を決める
（比率 1.0 = 0.5 で学習環境の評価と同じ）。学習環境（`khr_quad_env21.py`）の摩擦の乱数化は床 0.5 のため、比率 < 1 が効いていない（F12）。
