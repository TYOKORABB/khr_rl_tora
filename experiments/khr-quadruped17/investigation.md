# khr-quadruped17 (v17) 事前調査記録 — 膝の「swing−stance 差」を報酬にする（v16 ハックの修正）

- 記録日: 2026-07-31
- 位置づけ: v16 の報酬ハックを踏まえた修正版。目標は「犬のようにスムーズに関節を動かす歩行」。
  方針は [[project_roadmap]]。

## 1. これまでの傾向（v13〜v16 から得た設計則）

| 版 | 出来事 | 得られた設計則 |
|---|---|---|
| v13 | `feet_clearance` を**絶対高さ→接地基準からの相対量**に修正 → 前脚クリアランス3倍 | **絶対量ではなく、その部位自身の基準からの相対量で測る** |
| v14 | `base_height` 緩和 → 上下動 2.0→1.8mm と不変。仮説反証 | 「筋の通った仮説」でも実測で棄却される。**効いたか必ず測る** |
| v15 | 足裏水平を接地時のみに → 足首負荷 32→24%（部分的成功）。**膝の指令ROM自体が7°と判明** | **膝が動かない原因は報酬（指令が出ていない）**。物理制約ではない |
| v16 | 膝の**絶対角度**を報酬に → 目標角度で固定され ROM 2.7°（報酬ハック） | **「望む状態」ではなく「望む変化」を報酬にする** |

**v13 の成功と v16 の失敗は同じ構造**である。基準を「絶対値」に取ると失敗し、
「その部位自身の基準からの相対量」に取ると成功する。v17 はこの法則を膝に適用する。

## 2. v17 の対策（環境 khr_quad_env14 / 学習 khr_train_quad17）

**変更は1点**（v16 の報酬は削除して置き換え）。

| 変更 | 内容 |
|---|---|
| `_reward_knee_swing_flexion` 新設・`"knee_swing_flexion": 3.0` | 基準を **その脚自身の「接地時の膝角度」(EMA, α=0.05)** に取り、**遊脚中にそこから追加で曲がった分**だけを加点（目標 +0.25rad、飽和線形 `clamp(diff,0,target)/target`） |
| `"knee_flexion"`（v16, 位置ベース）を**削除** | 残すとハックが継続するため |

- **ハック耐性**: 定角度で固定すると接地時 EMA も同じ値になり **差がゼロ＝報酬 0**。
  v16 の「目標角度で固定して満点」は構造的に不可能。
- **形状**: 飽和線形。diff=0 で報酬 0（ただ乗り無し）、target で 1、それ以上は頭打ち。
- **scale 3.0**（v16 の 2.0 より強い）。v16 は一度動かせば済む**静的**な変化だったのに対し、
  v17 は**毎周期 関節を動かす**必要があり `dof_vel`/`action_rate`/`acceleration` のコストを
  繰り返し払うため、それを上回る誘因が要る。
- EMA は **接地相(leg_phase<0.55)のサンプルだけ**で更新する（遊脚相で更新すると差が消えるため）。

### 本版で「あえて対処しないこと」
v16 で悪化した接地の質（後脚 足裏傾き 16.1°）は**対処しない**。
着地直前に足裏水平を求めると**膝の屈曲を再び抑制し、主対策と干渉**する恐れがあるため、
膝が動くことを確認してから次版で扱う（v14/v15/v16 と同じく 1 変更＝ablation を明確化する方針）。

### 事前スモークテスト（学習前・num_envs=4）
- scale 3.0 / target 0.25 / EMA α=0.05 反映、全26報酬のメソッド対応 OK、報酬 finite。
- v16 のハック報酬が scales に残っていないことを assert で確認。
- **ハック耐性を検証**:
  - 【v16 と同じ固定戦略】膝を 0.70rad で固定（接地基準も 0.70）→ **報酬 0.0000**
  - 【差分あり】接地基準 0.40 → 遊脚で +0.25rad 屈曲 → **報酬 2.0000**

### v17 の合否指標（v16/v15比）
- **膝 ROM の回復（主目的）**: v16 2.7/2.8°・v15 7.2/7.8° → 増加（v8 の 22.3° が目安）。
- **swing−stance 差の増加**: v16 は +0.3〜1.5° しかなかった → 目標 +14°(0.25rad) に近づくこと。
- **指令 ROM も増えていること**（報酬が指令を変えたかの直接確認。v15 は指令 6.8〜7.4°）。
- **後脚クリアランスの増加**: 0.008/0.011m → 目標 0.02m へ。
- **トルク安全性の維持（必須）**: 飽和 0/22、ピークが定格80%を超えないこと。
- 追従・エピソード長が大きく崩れないこと。接地の質（足裏傾き16.1°）が更に悪化しないか監視。

> scale 3.0 は初期値。膝が暴れて着地の質やトルクが悪化するなら弱め、効果が出なければ強める。
