# khr-quadruped25 (v25) 事前調査記録 — 個体差下で横ずれが直らない原因は「観測できない量を罰していた」

- 記録日: 2026-08-20
- 位置づけ: v24 は**個体差なしで横ずれ 7.84→2.53%（2.8σ）**と主目的を達成したが、
  **個体差あり（関節オフセット ±1.15°）では 8.08→9.37% と効果が消えた**。実機は個体差を持つため、
  ここを解けないと実機には乗らない。**本版はその1点に絞る。**
- 環境: `khr_quad_env19.py`（env18 からの派生）／学習: `khr_train_quad25.py`

## 1. 診断 — 報酬が「隠れ状態」に依存していた（POMDP）

v24 は `heading_err`（累積ヘディング誤差）を**罰した**が、**観測には入れていなかった。**

方策が自分の旋回バイアスを検出できるか、数値で確認する。

| 量 | 値 |
|---|---|
| 個体差が生む yaw バイアス（実測 ±12.7°/10s より） | **≈ 0.022 rad/s** |
| 観測 `ang_vel` のノイズ振幅（`obs_noise['ang_vel']=0.1`, `obs_scales['ang_vel']=0.25`） | **±0.4 rad/s** |
| **S/N 比** | **≈ 1/18** |

**バイアスは瞬時観測ノイズの 1/18 に埋もれている。**
方策は MLP（履歴は `last_actions`/`last_dof_vel` の 1 ステップのみ）で**時間方向に平均化する手段を持たない**。
したがって **方策は自分の旋回バイアスを原理的に検出できない。**

一方で報酬は `heading_err²` を罰している。**`heading_err` は方策が観測できない隠れ状態である。**
これは POMDP であり、記憶を持たない方策に取れる最善は
「yaw 角速度の**分散**を下げる」ことであって、「**バイアス**を打ち消す」ことではない。

- 個体差なし → バイアスがゼロなので分散を下げるだけで横ずれは消える → **v24 は成功した**
- 個体差あり → バイアスが個体ごとに存在し、検出できないので打ち消せない → **v24 は失敗した**

**両者の結果は、この一つの仮説で無矛盾に説明できる。**

## 2. v25 の変更（1点）

| 変更 | 内容 |
|---|---|
| **`heading_err` を観測に追加** | actor 観測の末尾 `[121]` に `heading_err × 5.0` を追加（`num_obs` 121→122）。critic の特権観測にもノイズなしで追加（81 次元へ） |

**漏れ積分（τ≈10 秒 ＝ 500 ステップ）がローパスとして働き、ノイズを √500 ≈ 22 倍平均化する。**
これによりバイアスがノイズ床の上に出て、**罰されている量が方策から可観測になる。**

### 数値の根拠
- **スケール 5.0**: 定常時の `heading_err` は実測 0.157 rad → 観測値 0.78 となり、他の観測と同オーダーに揃う。
- **ノイズ 0.25**（scaled）＝ **±0.05 rad ＝ ±2.9°**: 実機ではジャイロ積分で得るため、
  積分誤差を想定して載せる。**完璧な信号に依存する方策を学習させない**ための措置。
  漏れ積分は時定数 10 秒でジャイロのバイアスドリフトを有界化するため、実機でも実現可能。

### 据え置き
`heading_error` の重み −10.0（v24 のまま。**変更を1点に保つため強化はしない**）、
`contact_duty_balance` 0.0（ablation で寄与なしと実証済み）、その他 v24 の全設定。

### 事前スモークテスト（学習前・num_envs=4）
- v24 との設定差が **`num_obs` / `obs_scales.heading_err` / `obs_noise.heading_err` の 3 件のみ**であることを機械的に確認。
- actor 観測 122 次元・特権観測 81 次元を確認。
- `heading_err=0.1566` → `obs[121]=0.783`、`heading_err=0` → `obs[121]=0.0` を確認（正しく反映）。
- ノイズ割当が `[121]=0.25`・`[120]=0.1`（既存の dof_vel）で、**既存レイアウトを壊していない**ことを確認。
- 報酬 finite。

## 3. 合否指標（v23 baseline 4seed の 2σ に対して）

| 指標 | 目標 |
|---|---|
| **横ずれ率（個体差あり）** | 8.08 ± 2.07% → **4.0% 以下**（2σ=4.14 を超える改善。本版の主目的） |
| yaw 累積の 8 体ばらつき（個体差あり） | ±12.7° → **±5° 以下** |
| 横ずれ率（個体差なし） | v24 の 2.53% を維持 |
| 90%超の時間 | **0 を維持（必須）** |
| 前進速度 | 0.227 ± 0.008 を維持 |
| 膝 ROM / 足裏傾き | 2σ 内を維持 |

> **反証可能性**: もし個体差ありで横ずれが改善しなければ、
> 「観測できないことが原因」という仮説は棄却される。その場合は
> 重みの不足（−10 → −30）か、個体差そのものを推定させる設計（履歴観測など）を次に試す。
