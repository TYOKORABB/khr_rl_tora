# khr-quadruped21 (v21) 事前調査記録 — v20の成果を保ちつつ、失ったトルク余裕と足裏接地を回復

- 記録日: 2026-08-11
- 位置づけ: v20 は実機の3課題のうち②を完全解決し①も改善したが、**既に獲得していた成果
  （トルク余裕・足裏全面接地・左右対称性）を損なった**。v21 でそれらを取り戻す。
- 環境コードの変更は無し（設定値のみ）。**`khr_quad_env16.py` を流用**（v19 と同じ方針）。

## 1. 出発点: v20 の到達点と失ったもの

### 維持したい成果（v20 で得たもの）

| 項目 | 内容 |
|---|---|
| ② 後退の速度 | 0.164 → **0.269 m/s**（前進 0.266 とほぼ同等）。`lin_vel_x_range` [-0.3,0.3] |
| ① 横ずれ | 個体差なし 5%→**3%**、個体差±1.15°の8体で 12.3%±9.9 → **8.3%±6.5** |
| ③ 旋回（左） | 中心のずれ 0.033 → **0.005 m** |
| 速度 | 前進 0.248 → 0.266 m/s |

### 取り戻したいもの（v20 で失ったもの）

| 項目 | v19 | v20 | 目標 |
|---|---|---|---|
| **ピーク\|τ\|（個体差あり）** | 82% | **100%** ⚠️ | **90%未満** |
| **後脚 足裏傾き（接地時平均）** | 8.4° | **13.3°** | 10°以内（v18 は 6.1°） |
| 後脚 接地率 左右差 | 3.0 pt | **9.5 pt** | 5pt 以内 |

（③の右旋回の悪化 0.024→0.062m も左右非対称に起因する可能性がある）

## 2. v21 の変更（数値調整のみ、4点）

| 目的 | 変更 |
|---|---|
| **トルク余裕の回復（最優先）** | `torque_soft_ratio` **0.65 → 0.60**（罰の対象範囲を拡大）＋ `torque_limits` **-5.0 → -8.0**（強度を上げる）。定格100%到達時の罰は **2.09倍**（学習前に検算） |
| **足裏全面接地の回復** | `feet_orientation` **-3.0 → -4.5**（1.5倍）。v18 で 6.1° を達成した仕組み（着地直前からの水平要求）は維持し、重みのみ強化 |
| **左右対称性の回復** | `leg_load_balance` **-1.0 → -2.0**。③の右旋回の悪化にも効くことを期待 |

### 維持する設定（明示）
- **v20 由来**: `lin_vel_x_range` [-0.3, 0.3]（②）、`_reward_drift` の vx 成分（③）、
  関節オフセットDR ±0.02rad（①）
- **v19 由来**: `tracking_sigma` 0.08 / `tracking_lin_vel` 5.0（速度の限界価値）
- `knee_swing_flexion` 1.8、`heading_drift` -40、`drift` -10 など

## 3. リスクと監視項目

- **罰を3つ同時に強めるため速度が落ちる恐れ**。前例として v18 では `feet_orientation` を
  -3.0 に強めた結果、前進追従が **57%** まで低下した。
  ただし当時と異なり、いまは v19 の tracking 設定（sigma 0.08 / scale 5.0）が
  **速度側の対抗力として残っている**ため、同じようには落ちない見込み。
- 前進 0.266 / 後退 0.269 m/s を大きく落とさないこと。
- 膝 ROM（v19 で 26〜30°）が潰れないこと。

### 事前スモークテスト（学習前・num_envs=4）
- 回復4点（soft比 0.60 / torque_limits -8.0 / feet_orientation -4.5 / leg_load_balance -2.0）反映。
- 維持3点（後退範囲 [-0.3,0.3] / 関節オフセットDR True / tracking 0.08・5.0）を assert で確認。
- **トルク罰の強度を検算**: 定格100%到達時 v20 −1.155 → v21 −2.413（**2.09倍**）。
- 全26報酬のメソッド対応 OK、報酬 finite。

## 4. 学習と検証（このあと）

```bash
python khr_train_quad21.py -e khr-quadruped21 -B 4096 -I 4000 --seed 1
python khr_quad_report.py -e khr-quadruped21
```

**必ず「個体差なし」と「個体差±1.15°あり」の両条件で測る**（v20 で条件の混在により

| 指標 | 目標 |

| **ピーク\|τ\|（個体差あり）** | 100% → **90%未満**（最優先。要件「100%は絶対NG」） |
| **後脚 足裏傾き** | 13.3° → **10°以内** |
| 後脚 接地率 左右差 | 9.5pt → 5pt 以内 |
| 後退の速度 | **0.25 m/s 以上を維持**（v20 は 0.269） |
| 前進の速度・追従 | **0.25 m/s 以上を維持**（v20 は 0.266） |
| 横ずれ（個体差あり） | 8.3% を維持または改善 |
| 旋回の中心ずれ | 左右とも 0.03m 以内（右旋回は複数試行で確認） |
| 膝 ROM | 20〜35° を維持 |
