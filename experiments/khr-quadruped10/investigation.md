## 1. フィードバック（教授・実機観察）

v9 の動作に対し:
1. **トルク100%はモーター焼損リスクで実機では相当危険。100%は絶対NG、負荷はなるべく低く。**
2. **前進を指令しているのに横に逸れる。**
3. **ところどころカクッとした動きがある（滑らかにしたい）。**

## 2. 定量診断（v9 model_3999, 前進0.4, ノイズ/DR無効）

### 決定的発見: 歩容が左右非対称（右後脚に荷重集中）

| 項目 | 値 |
|---|---|
| l_hip_pitch 負荷 | 平均56%（張り付き time率 9%） |
| **r_hip_pitch 負荷** | **平均100%（張り付き time率 100%）** |
| 前脚(腕8軸) 平均負荷 | 22%（最大69%）← 余裕あり |
| 後脚(脚12軸) 平均負荷 | 32%（最大100%＝r_hip） |
| 横速度 vy（指令0） | +0.030 m/s |
| 旋回 yaw（指令0） | +0.028 rad/s（10秒で16度ずれ） |
| 横傾き(重力y) | +0.012（ほぼ水平） |

→ **方策が右後脚だけに体重を預ける非対称歩容を学習**。これが
**② 右hip_pitchの100%飽和** と **横逸れ（前進なのに横・首振り）** の**両方の原因**。
つまり左右対称化が両者を同時に解く最大レバー。前脚に余裕があるのに後脚が飽和＝荷重の偏りが本質。

（base roll −40.9°は胴体90°ピッチの座標表現上の見かけ。実横傾きは重力y=+0.012＝ほぼ水平。）

## 3. v10 の対策（環境 khr_quad_env7 / 学習 khr_train_quad10）

方針（ユーザー承認: 「報酬で対称化＋減速」）。姿勢・トロットは v8/v9 のまま、報酬側で対症。
「100%を許さない」には罰の強化だけでなく**荷重ピーク自体を下げる**必要があるため減速も併用。

| 変更 | 対応 | 内容 |
|---|---|---|
| `_reward_leg_load_balance` -1.0 | ②横逸れ | 左右後脚の平均トルク負荷(EMA, α=0.02)の差を罰し片脚集中を是正（主対策）。トロットは左右が半周期ずれ瞬時比較不可のため時間平均で測る |
| `_reward_drift` -10.0 | 横逸れ | 指令からの横速度/旋回のズレを二乗で罰し直進時の横逸れを補助的に抑制 |
| `_reward_action_smoothness2` -0.01 | ③カクつき | 行動の2階差分(躍度) `(a_t−2a_{t-1}+a_{t-2})²` を罰す |
| `torque_limits` 強化 | ①100%禁止 | soft比 0.85→0.65、scale −2.0→−5.0（定格65%超を強く罰し100%張り付きを禁止） |
| `lin_vel_x_range` 0.4→0.3 | 低負荷 | 前進上限を下げ推進トルクのピークを低減。後退 −0.2 は維持 |
| v9 の対策維持 | — | dof_pos_error(−1.0) 等は継続 |

実装の要点:
- `step` でトルクを `self.torques` にキャッシュし、左右後脚 |τ| の総和を EMA 更新（`leg_tau_ema_l/r`）。
- `last_last_actions` を追加し2階差分を計算。いずれもエピソードreset時にゼロ化。

### 事前スモークテスト（学習前・num_envs=4）

- 後退範囲 [-0.2,0.3]・soft比0.65・全23報酬のメソッド対応 OK。
- ランダム行動で leg_load_balance/drift/action_smoothness2/torque_limits がいずれも非ゼロ・有限、
  step報酬 finite。→ 環境・新報酬とも正常動作。
- 注: 新報酬 scale は初期値。drift はランダム時に過大だったため -30→-10 に減衰し、
  対称化の主対策を leg_load_balance(-1.0) に置いた。

## 4. 学習と検証（このあと）

```bash
python khr_train_quad10.py -e khr-quadruped10 -B 4096 -I 4000 --seed 1
python khr_quad_report.py -e khr-quadruped10
```

### v10 の合否指標（v9比）
- **どの関節も 100% 張り付きが無いこと**（最重要・実機安全）。r_hip_pitch の平均負荷が100%→大幅低下。
- **左右後脚の平均負荷が対称**（l/r_hip_pitch の差が縮小）。
- **前進時の横逸れ vy/yaw が縮小**（+0.030/+0.028 → 0付近）。
- **滑らかさ（|Δaction|RMS・dof_vel・2階差分）の低下**。
- 前進/後退/横/旋回の追従が破綻しない（減速で前進上限0.3に下がる点は許容）。

> 学習後に 100% が残る場合は torque_limits/leg_load_balance をさらに強め、
> 歩容が消える(立ち止まる)場合は弱める。次段(v11)でミラー対称化学習/クロール歩容を検討。
