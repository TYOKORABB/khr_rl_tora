「押していない」は、通電している間に左肘（右肘）のずれが 3° を超えた時間のうち、電流の読みが 0.1 A 以下だった時間（割合）。11/10 の故障の形は、これが 2 秒以上続くこと。条件の時刻は方策の開始から。

- 置き方（方策の開始時の関節角）: 11/10 の固定ありの 2 回は、股関節のピッチ −84〜−105°、膝 46〜68°、肩ロール 0〜4°（腕は体の横）。14:13・14:14 は Claude が「手足を伸ばして」と頼んだため脚が伸び（右膝 2〜4°）、右腕が開いていた（肩ロール −20〜−26°）。14:20 と 14:39 は 11/10 にそろえた（股関節 −90〜−94°、膝 64〜80°）。
- 14:39 と 14:41 は寝返りして四脚の姿勢の近くまで行ったが、方策の終わりにも胸ヨーが四脚の姿勢から 18〜19° ずれていて（関節角の上限 17.2°）、8 秒の中で 4 条件がそろわなかった。14:39 は保持の間（8.5 秒以降）に 4 条件がそろった。11/10 の成功した回は、方策の終わりの胸ヨーが ±3° 以内で、胸の向きの条件も 2.3〜2.5 秒でそろっていた。
- 左肘の押していない割合は、11/10 の仰向け 11〜13 % に対して、今日の仰向けのねじを締める前の 3 回が 39〜56 %、締めた後の 2 回が 18〜24 %。右肘は両日とも 2〜14 %。左肘だけ高い回があるが、最長はどれも 0.16 秒以下で、11/10 の止まり方とは違う。腰のガタつきや置き方の違いと分けられていない。
- 参考: 符号つきで向きごとに分けても、左肘はどちらの向きでも押していない時間があり、片方の向きだけ駆動できない形ではなかった（その場の計算、記録は残していない）。
