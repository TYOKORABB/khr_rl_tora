# 実機 3 回目（2026-11-10、研究室）: 歩行の速さと傾きのずれ

同じ日の起き上がりは `../20261110_getup_r2/README.md`。方策は 10/13 と同じ v31（khr-quadruped31-s2 model_3999）、`real/walk_session.py`。
床は研究室の普通の床。距離は本人がメジャーで測った**目視の値**（頭のてっぺんの位置）。

## 傾きのずれ（四脚の初期姿勢で保持）

| 測り方 | 左右 | 前後 |
|---|---|---|
| スマホの傾斜計（背中の板に載せた） | ほぼ 0° | 頭が上に約 6° |
| IMU（`walk_session status`、同じとき） | 左が下 0.73° | 頭が上 4.86° |

- 読み方は `../session2_plan.md` の 6（測る前に決めてあった）: 両方が同じだけずれていれば体の形（関節の 0 点）、IMU だけがずれていれば取り付けの校正。
- 傾斜計と IMU は両方の向きで 1° 前後の差で合った。止まっているときの「頭が上」のずれ（実機 − 学習環境 = 前後 −3.0°、`experiments/sysid/README.md`）は、IMU の取り付けの誤差が主ではなく、胴体そのものが傾いている側（形・関節の 0 点・姿勢）と読む。今日の歩き出す前の足踏みの区間でも、前後の傾きは実機 −5.0〜−5.8°（有効な 6 回）、学習環境 −2.6°（`analysis.json`）。
- 限界: 背中の板と IMU の座標の軸が平行かは確かめていない。傾斜計の読みは 1° 単位の 1 回だけ。床の傾きは測っていない（IMU と傾斜計の比較には効かないが、学習環境との比較には効く）。
- シミュで関節の 0 点を ±2° ずらしても前後の傾きは 0〜+1.0° しか変わらなかった（同 §1）ので、どの関節かは分からない。

- 実機の進んだ距離は kp 25 の 74 %（前進）、58〜63 %（後退）。kp 7 と kp 15 のあいだに入る（直線で内挿すると前進 kp ≒ 12、後退 kp ≒ 10）。
- 10/13 の旋回の比（実機 0.88）も kp 7（0.63）と kp 15（0.97）のあいだだった（`experiments/sysid/walk_sweep/kp0.28.json`、`docs/GetUpOverview.md` §7）。起き上がりの当てはめ（kp ≒ 7）より、歩行は硬く見える。負荷の大きさで実効の硬さが変わる、などの説明が考えられるが、確かめていない（重りの試験は本人の研究では扱わないと決めた）。
- 横のずれ: 前進の 3 回は 116〜117 cm 進んで右へ 42〜43 cm（約 20° 斜め）だが、向きの変化は −2.7〜−4.7° しかなく、その大半は歩き出す前の足踏みの間に起きている（歩いている区間の回る速さは −0.1〜−0.7°/s）。体の向きをあまり変えずに右へ流れている。学習環境の横の移動は前進 1.8 cm・後退 10.5 cm（kp 25、どちらも機体の左へ）。後退でも同じ向きへ 46〜60 cm 流れた。床・足の滑り・左右の差のどれが原因かは分からない。
- 歩き出す前の 2 秒の足踏み（指令 0）で、実機は右回りに 2.6〜5.8°/s 回っていた（有効な 6 回、学習環境 +0.4°/s）。止まったあとの足踏みでは −0.5〜+1.8°/s（学習環境 −0.5〜+1.3°/s）。`analysis.json`、各区間の最初の 0.5 秒を除く。
- 1 回の値は目視で、測る点（頭のてっぺん）と学習環境の点（胴体）が違う。回数は前進 3・後退 3。
