# 次の実機の手順（11/17 作成、案）: kpj-kplow と v12 を並べて試す

シミュの結果は `experiments/getup/v13_plan.md` §7.6・§8。前回（11/13）は `20261113_hw_check/README.md`。
物理の操作（BOOT・置く・持つ・配線）は、そのつど直前に確認を取る。**動かす直前に撮影するかを本人に確かめる**（11/10 の本人の指示）。
サーボの設定は読むだけで書き換えない（プロテクションは外さない）。扱わないこと: 重りの試験・ステップ応答（同期のテーマ）。

## 目的

1. getup-v13 の採用候補 kpj-kplow（`getup13-kpj-kplow-s6` の model_7496）を実機で動かし、v12（`getup12-real-s3` の model_5997、11/10・11/13 に使ったもの）と同じ置き方で並べる。
2. 仰向けを、11/10 の固定ありの回と同じ置き方で比べ直す（11/13 は置き方がそろっていなかった）。

シミュでの違い（比例ゲイン 7・ずれの上限 0.08 rad。比例ゲイン 5・6 は「サーボが弱い日」の物差し）:

| 量 | v12 シード 3 | kpj-kplow シード 6 |
|---|---|---|
| 実機の仰向けの始めの姿勢 17 個 × 8 回 | 98.5 % | 100 % |
| 同じく寝返りの時間（中央値） | 3.36 s | 2.99 s |
| 比例ゲイン 6 の仰向け | 86.0 % | 100 % |
| 比例ゲイン 5 の仰向け | 8.1 % | 63.2 % |
| 比例ゲイン 5 のうつ伏せ | 12.5 % | 68.8 % |

## 実機なしで済ませたこと（11/17）

- `python -m real.getup_session getup-selftest --exp getup13-kpj-kplow-s6 --ckpt 7496 --e-sat-deg 7`: OK（偽の ESP32 で通電 → 起き上がり → 固定 → 脱力まで通る。cfgs.pkl の新しい設定 kp_per_joint などは読み込みに影響しない）。
- `obs-check`（学習環境の観測と、実機から届く形にした観測の一致）: v12 シード 3 と同じ程度の差（関節角の 99 % 点 0.016 rad など。学習環境の 0 点のずれ ±0.02 rad などの個体差の分）。v12 は同じ値で 11/10 に動いたので、新しい違いはない。結果のファイルは上書きしないよう元に戻した。

- シミュの参考（`../getup/v13_plan.md` §8.2）: サーボ 1 個が半分の強さなら kpj-kplow はどの関節でも 93 % 以上起き上がる（v12 は肩ピッチで 52〜64 %）。1 個が脱力だと、どちらの方策も起き上がれない（肩ピッチ・肘ピッチ・胸ヨーの仰向け）。**動かす前のサーボの確認（順 1）は省かない。**
- ずれの上限 0.10 rad では、比例ゲイン 1 段分強くなる（比例ゲイン × ずれの上限で成功がほぼ決まる）。

## 読み方（案。本人と決めてから試す）

- 回数が少ない（各 2〜4 回）ので、成功率の差は主張しない。「kpj-kplow が実機で起き上がれるか」「同じ置き方で v12 と寝返りの時間・判定までの時間・左肘の押していない割合がどう違うか」を並べて書く。
