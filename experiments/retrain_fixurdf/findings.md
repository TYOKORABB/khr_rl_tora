# 再学習から分かったこと

**暫定（2026-10-07 時点・14/88 完了）。** seed が揃うたびに更新する。

## 0. 結論 — 「結局 URDF は影響していたのか」

**v1〜v14 には深刻に影響した。v15 以降は軽微だった。**

`check_joint_saturation.py` で、各版のポリシーが股関節 pitch の可動域の端に
どれだけ押し付けられていたかを実測した（当時のまま＝是正を当てない状態、16 体・8 秒）。

| 版 | 端に張り付いていた時間 | 右が使った範囲 | 状態 |
|---|---|---|---|
| **v8** | **100 %** | **0.7 °** | **股関節が事実上ロック。歩容は膝と足首だけ** |
| v15 | 12.4 % | 15.1 ° | 制約として効いていない |
| v19 | 10.9 % | 14.6 ° | 同 |
| v23 | 10.9 % | 12.7 ° | 同 |
| v27 | 7.4 % | 14.9 ° | 同 |
| v28 | 4.4 % | 16.7 ° | 同 |

### 効いていたのは「上限の鏡像」ではなく「下限が 10° 足りないこと」

**上限（右 +110° / 左 +100°）には、どの版も一度も触れていない**（張り付き 0.0 %、
実際に使った最大角は −78〜−85° 付近）。股関節は負側だけで動いている。

問題は下限だった。左は −110.0° まで使えるのに、**右は −100.0° で止まる**。
つまり**実際に使う側で右脚だけ 10° 短い**。これが左右差の正体。

### 是正すると右脚は実際にその余裕を使い始める

| | 右が使った範囲 | 右の最小角 |
|---|---|---|
| v23 当時のまま | 12.7 ° | −100.2°（下限で頭打ち） |
| **v23 是正後** | **17.6 °** | **−110.6°** |
| v28 当時のまま | 16.7 ° | −99.1° |
| **v28 是正後** | **23.7 °** | **−109.6°** |
| v31（是正 + トルク −12） | 19.8 ° | −110.0° |

是正は「気のせい」ではなく、**右脚に実際に 5〜7° の可動を足している。**

### それでも標準指標はほとんど動かない

| | v27 是正前 → 後 | 判定 |
|---|---|---|
| 股関節の左右差 | 8.18 → 4.15 ° | **半減** |
| 接地率の左右差 | 3.69 → 7.19 pt | **6.3σ 悪化** |
| トルク平均・99%点・横ずれ・速度・膝ROM・足裏傾き・歩容一致・転倒 | | **すべて差なし** |

### この問いへの答えとして

1. **v8 前後（v1〜v14）の記録は「片脚を縛った状態」として読む必要がある。**
   特に v8 は股関節が完全にロックされており、当時の考察のうち
   「股関節の使い方」に関する部分は成り立たない。
2. **v15 以降では制約として効いていない**（張り付き 4〜12 %）。
   報酬の必要/不要の判定（§4.33 の 27 本 ablation）は v27 を基準に行っており、
   v27 の張り付きは 7.4 % なので、**この判定は是正後もそのまま使える。**
3. **是正の効果は左右対称性に出る**（8.2° → 4.2°、v31 で 0.80°）。
   論文では「左右差」の節で是正後の値を使い、
   それ以外の指標では是正前後で差が無かったことを述べるのが正確。
4. 88 本の再学習は**結論を覆すためではなく、是正後の揃った数値を揃えるため**に続ける。

## 1. 可動域の是正は「左右差を半減させるが、別の不均衡を生む」

報酬構成を完全に同一にして URDF だけを替えた比較（128 体・3 seed）。
これが**是正の効果だけを切り出せる唯一の実験**。

**解釈**: v1〜v29 の報酬は、**可動域を縛られた機体に合わせて暗黙に調整されていた**。
可動域が正しく広がると、方策はその余裕を使い始めるが、
「使い方」を縛る報酬が無いため接地時間が左右で偏る。
股関節が動けるようになったこと自体は正しく、不足しているのは報酬側の指定。

**【2026-10-11 追記】v28 の 3 seed が揃った。** §6 を参照。
1 seed で見えていた「接地率左右差の悪化」は 3 seed では差なしに収まり、
代わりに**トルク 99%点が 3.0σ 悪化**していた。劣化の出方は版によって違う。

## 4. 横ずれ率のばらつきは測定ノイズではなかった

ノイズ床を 8 体 → 128 体で作り直したところ、ほとんどの指標の 2σ は 2〜3 倍縮んだのに、
**横ずれ率だけ縮まらなかった**（4.15 → 4.43）。

体数を増やしても縮まない＝**測定の荒さではなく、seed 間で方策そのものが変わる量**。
横ずれを 1 つの学習結果で語ることはできず、常に複数 seed が必要。

### 読み取れること

1. **v1〜v8 は「歩けていない」**。トルク平均 24〜47 %、**99%点が 100 %（＝常時飽和）**、

### ⚠ v11 の数値は「是正の影響」ではない

v11 は**是正前から既知の失敗版**（§4.13「瞬時 yaw 罰で並進崩壊」）。
是正後も速度 0.0019 m/s＝ほぼ立ち止まるだけで、これは当時と同じ挙動。

このとき**横ずれ率（横移動 ÷ 前進距離）は定義として破綻する。**
前進が 0 に近いと分母が 0 に近づくため、v11 の「2013 %」や seed1 の「5959 %」は
比率の発散であって横ずれの大きさではない。seed1 の転倒 768 も発散した結果。

**測定上の注意**: 横ずれ率は**前進している版にしか意味がない**。
速度が 0.05 m/s を下回る版（v1, v11）ではこの指標を読まないこと。
