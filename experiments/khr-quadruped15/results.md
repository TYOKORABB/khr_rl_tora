# khr-quadruped15 (v15) 検証結果 — 🟡 仮説は部分的に正しかったが主目的は未達。ただし**真因を特定**

- 記録日: 2026-07-30（学習: 4096env × 4000iter, seed=1, 所要 1h04m, 最終 model_3999。完走）
- 対策の意図は同ディレクトリ `investigation.md` を参照。
- 評価はノイズ/DR無効・loco座標系。前進は在範囲0.3。

## 1. 仮説の検証結果: 部分的に正しかった

「足裏水平罰が遊脚中も効いて足首に仕事が集中している」という仮説は、**足首については当たった**。

| 後脚 | v14 | v15 |
|---|---|---|
| l_ankle_pitch 負荷 | **32%** | **24%** |
| r_ankle_pitch 負荷 | 26% | 22% |
| l_hip_pitch 負荷 | 32% | 23% |
| r_hip_pitch 負荷 | 26% | 29% |
| **l_knee_pitch ROM** | 6.4° | **7.2°** |
| **r_knee_pitch ROM** | 14.8° | **7.8°** |

- **足首の負荷が 32% → 24% へ低下**し、「足首が突出して最大」という状態は緩和された（仮説の裏付け）。
- しかし **膝 ROM は 7.2°/7.8° と回復せず**（v13 は 9.6/10.2、v8 は 22.3°）。主目的は未達。

## 2. 【最重要】追加診断で真因を特定 — 膝は「動けない」のではなく「動かす指令が出ていない」

PD の**指令角**と**実測角**の可動域を比較した（前進0.3, 10秒）。

| 関節 | 指令ROM | 実測ROM | 追従率 |
|---|---|---|---|
| l_hip_pitch | 14.2° | 15.6° | 110% |
| **l_knee_pitch** | **6.8°** | 7.8° | 114% |
| l_ankle_pitch | 13.0° | 12.6° | 97% |
| r_hip_pitch | 14.6° | 15.0° | 102% |
| **r_knee_pitch** | **7.4°** | 8.4° | 115% |
| r_ankle_pitch | 12.2° | 11.8° | 96% |

**膝の指令 ROM 自体が 6.8〜7.4° しかなく、実測はそれをむしろ上回っている（追従率110〜115%）。**

→ **トルク不足や PD の追従限界で膝が動かないのではない。方策が膝を動かす指令を出していない。**
   つまり原因は完全に**報酬設計（方策の選択）**にある。これで `torque_limits` は容疑から外れた。

### なぜ膝を使わないのか（推定）

- 遊脚は **股関節の回転だけ**で振られている（hip ROM 15°）。膝を曲げなくても一応足は前に出る。
- **膝の屈曲を直接求める報酬が存在しない**。`feet_clearance` は足の高さを見るだけなので、
  股関節主体でも部分的に満たせる（ただし剛体脚の円弧運動では十分な高さを稼げず、
  後脚クリアランスが 0.007〜0.010m で頭打ちになっている）。
- 一方で関節運動には広くコストがかかる（`dof_vel` −0.001, `action_rate` −0.02,
  `action_smoothness2` −0.01, `acceleration` −0.00004, `dof_pos_error` −1.0）。
  **「膝を曲げる利益がなく、動かすコストだけある」**ため、方策は膝を固めて股関節だけで振る。

これは犬・馬などの四足が **遊脚期に膝を曲げて脚を短縮し、地面を避ける** のと正反対の戦略である。

## 3. 副作用: 接地の質は悪化（想定どおり）

| 指標 | v14 | v15 |
|---|---|---|
| 後脚 足裏傾き（接地時平均） | 11.0° | **13.5°** |
| 足裏傾き 左/右 | 7.8 / 9.8° | 11.0 / 13.9° |

遊脚中の足裏を自由にした代償として、**接地時の足裏の傾きが悪化**した。
v7 で対処した「足の縁で歩く」問題の軽度な再発であり、実機では接地の不安定化につながりうる。

## 5. 総合評価

| 項目 | 判定 |

## 6. 次（v16 候補）: 膝の屈曲を直接促す

真因が「膝を曲げる利益がない」ことなので、**遊脚期の膝屈曲を直接報酬にする**のが最も直接的。

1. **遊脚期の膝屈曲報酬を新設**（本命）。swing 中に膝が default より曲がっているほど加点。
   犬・馬が遊脚期に脚を短縮するのと同じ原理で、説明もしやすい。
2. 関節運動のコストを下げる（`dof_vel` / `action_rate` / `dof_pos_error` の緩和）。
   ただしトルク飽和・カクつきの再発リスクがある。
3. 接地の質の悪化（足裏傾き13.5°）への対処: `feet_orientation` を
   「接地時のみ」から「接地時＋着地直前」に広げる中間案。
