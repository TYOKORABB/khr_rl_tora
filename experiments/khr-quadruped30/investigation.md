# khr-quadruped30 (v30) 事前調査記録 — 歩容の左右非対称は URDF のバグだった

- 記録日: 2026-10-06
- 発端: 「後ろ足の動きが不自然」という指摘の原因追及
- 変更: **報酬は v28 のまま。URDF の `r_hip_pitch` 可動域の左右非対称を是正しただけ。**

## 1. 「不自然さ」の候補を 3 つつぶした

| 候補 | 判定 |
|---|---|
| 歩容の形（足先軌道・滑り） | ❌ 正常。立脚で 4.1 cm 後退・遊脚で 4.6 cm 前進、滑り 20〜23 %（全版同じ） |
| 接地の分断（着地で跳ねる） | ❌ **跳ねていない。** 分断の中央値は 20 ms = **制御1ステップ**で、その間の足の高さ変化は **−0.49 mm（むしろ下降）**、直前の法線力は 9.5 N。物理的な跳ねではなく**接触力の1ステップ欠落**。96 % が 0.5 mm 未満 |
| **左右非対称** | ✅ **実在。しかも原因は URDF にあった** |

## 2. 根本原因: `r_hip_pitch` の可動域が鏡像になっていた

| 関節 | 軸 | 下限 | 上限 | 既定値 |
|---|---|---|---|---|
| `l_hip_pitch` | [0,1,0] | **−110.0°** | +100.0° | −101.4° |
| `r_hip_pitch` | [0,1,0] | **−100.0°** | +110.0° | −101.4° ★**下限を 1.41° 超過** |

**軸は左右とも [0,1,0] で同一なのに、可動域だけが鏡像。**
hip_pitch は脚を前後に振る関節で左右の区別がないため、**可動域を鏡像にするのは誤り**である
（roll 系の鏡像は「外旋/内旋」を表すので正しい。そちらは触らない）。

結果:
- 脚を後ろへ振る余裕が **左 8.6° / 右 1.4°** ＝ **10.0° の差**
- 既定姿勢 −101.4° が **右の下限 −100.0° の外側**

### 実測で裏づけ

| | 実測レンジ | 下限 | 下限から 1° 以内にいる割合 |
|---|---|---|---|
| v28 左 hip_pitch | −110.4° 〜 −90.3° | −110.0° | **11.7 %** |
| v28 右 hip_pitch | −99.1° 〜 −82.8° | −100.0° | 0 % |
| v27 左 hip_pitch | −109.4° 〜 −91.1° | −110.0° | 5.0 % |
| v27 右 hip_pitch | −100.1° 〜 −85.2° | −100.0° | **12.8 %** |

**両脚が約 10° ずれた別々の角度窓で動いており、どちらも自分の下限に張り付いている。**
実測の股関節左右差（v27 8.18° / v28 8.62°）とぴたり一致する。

> **非対称は学習の結果ではなく、モデルに強制されていた。**
> v29 で `leg_load_balance` と `hip_pos` を戻しても直らなかったのは当然で、
> 報酬をどう変えても可動域の制約は超えられない。

## 3. v30 の変更（1 点）

`assets/khr3hv/urdf/khr3hv_symhip.urdf` を**新規に追加**し、`r_hip_pitch` の可動域を
`l_hip_pitch` と同一（−1.919862177, 1.745329252）にした。

- **元の `khr3hv.urdf` は一切変更していない。** 過去の全バージョンは引き続き再現可能。
- 変更したのは `r_hip_pitch` の可動域のみ（XML 比較で検証済み。link/joint 数も不変）。
- 環境は `khr_quad_env21.py`（env19 の URDF 参照だけを差し替え。AST 比較で差分は `__init__` のみ）。
- 学習は `khr_train_quad30.py`（**v28 と報酬・設定の差分ゼロ**）。

## 4. 合否指標

| 指標 | 目標 |
|---|---|
| **股関節 hip_pitch の左右差** | v28 8.62° → **4° 以下**（本版の主目的） |
| 立脚中心ずれ | ±0.5 cm 以内 |
| 接地率 左右差 | v28 3.97 pt → 改善 |
| 横ずれ・前進速度・トルク安全性 | v28 水準を維持 |
| 横移動 | v28 の 77 % を維持 |

> **反証可能性**: 左右差が 4° 以下にならなければ、可動域以外に原因がある。
> その場合は PD ゲインや初期姿勢の左右差を疑う。
