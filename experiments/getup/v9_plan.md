# getup-v9（左右対称の利用）— 計画と判定の基準（学習の前に固定、2026-11-04）

## 0. きっかけ

ユーザーの決定（11/4）:「候補の手法を優先度順に試してほしい。Dはやらなくて良い。とりあえずAは今実装して学習を回して。」

候補は `docs/GetUpImprovementOptions.md`。ここでは A（左右対称）を行う。B・C はこの結果を受けて、優先度順に続ける。D は行わない。

## 1. 根拠（`docs/GetUpImprovementOptions.md` §2）

- 胸を向けられない失敗は、ほぼ「左の体側を下にした横倒しから先へ進めない」の 1 点。右が下なら 89〜99 %、左が下だと 1〜5 %（止まる 4 方策）。
- 左が下のときに観測と行動を左右反転すると、学習し直さずに転んだ状態が全シード 88 % 以上。

## 2. 構成

土台は v7 の B（hard ＋ flipthr、L3、3000 イテレーション）。変えるのは下の表だけで、L4 は入れない。

| 構成 | 内容 | 学習 | 動かすときのスイッチ |
|---|---|---|---|
| A1 スイッチ | v7 の B の方策（`getup7-hardflip-s{1,2,3}`）をそのまま、左右反転のスイッチで動かす | しない | 要る |
| A2a canon（`getup9-canon-s{1,2,3}`） | 同じスイッチを入れて学習する。方策は常に右が下の形だけを見る | 3 シード | 要る |
| A2b sym（`getup9-sym-s{1,2,3}`） | rsl-rl の対称性のデータ拡張（ミニバッチに鏡像を足す、Mittal ら） | 3 シード | 要らない |

スイッチの規則（3 つとも共通の部品 `khr_common/mirror.py`、環境 `getup_env3` の `mirror_switch`）: 観測の重力の値で、|gy| > 0.5 かつ u < 0.7 のあいだ「左が下なら反転」を更新し、u ≥ 0.7 に達したら固定する。エピソードの始めに解除する。

## 3. 判定の基準（学習の前に固定）

v8 と同じ 8 条件を、構成ごとに見る。主な指標 F は歩行中に転んだ状態の全部の成功率（`eval_getup` の `falls_all`、ドメインランダム化あり、8 秒、229 状態）。

| 種類 | 条件 | v7 の B | v8 |
|---|---|---|---|
| 主な指標 | F が 3 シードの平均で 85 % 以上 | 73.5 | 40.9 |
| どのシードでも解ける | F が 3 シードとも 70 % 以上 | 最低 28.0 | 最低 27.1 |
| L4 の範囲 | L4 相当の成功が 3 シードの平均で 80 % 以上 | — | 61.8 |
| 悪くしない 1 | L3 の成功が 3 シードの平均で 80 % 以上 | 91.3 | 81.2 |
| 悪くしない 2 | L2 の成功が 3 シードの平均で 85 % 以上 | 92.3 | 84.8 |
| 悪くしない 3 | u0 ≥ 0.5 の脱力の状態の成功が 3 シードの平均で 85 % 以上 | 92.5 | 86.1 |
| 悪くしない 4 | 脱力の横倒しの範囲 M が 3 シードの平均で 70 % 以上 | 82.2 | 56.7 |
| 悪くしない 5 | トルクが上限に張り付く時間が 3 シードとも 1 % 未満 | 最大 0.095 | 最大 0.263 |

- L4 相当 = L4 の 4,204 状態のうちの成功の割合。段階 L3 の検証・`--states chest_up`・`--states falls` の u0 < 0 の状態、の 3 つの実行を合わせて数える（B は段階 L4 を持たないので、同じ状態を 3 回に分けて測る）。
- 採る構成: 合格したもののうち、F の最低シードが最も高いもの。2 pt 以内で並べば、u0 ≥ 0.9 の成功の平均（実機に近い条件）が高いもの。
- 3 シードがそろうまで判定しない。
- A1 の評価の状態は、診断（`diag_mirror`）で既に一度見ている。基準はその後で決めたので、A1 の判定は確認の意味が強い。A2 の学習は評価の状態を使わない。
- 参考（判定には使わない）: 主のバンクの胸が上の状態、u0 ≥ 0.9、失敗の型（`failure_modes`）、トルクの 99 % 点、成功までの時間、立った後の揺れ（A2 だけ）、昇格のイテレーション。
- 動画: 検証のたびに撮る。段階ごと、脱力の横倒し、転んだ状態、胸が上の状態。A1 は `*_mirror*.mp4`。画面に「左右反転中」を出す。

## 4. 事前の見立て（外れたらそれも記録する）

- A1: F の平均 93〜98 %、最低 90 % 以上。合格。B シード 3 はほとんど変わらない。
- A2a canon: F の平均 90〜98 %、最低 85 % 以上。見る状態が半分になるので、シードによる割れが減る。A1 と同じか少し上。
- A2b sym: F の平均 75〜95 %、最低 50〜90 %。canon より不確か（単純なデータ拡張は効きにくいという報告がある）。学習の 1 イテレーションは 2〜3 割遅くなる。
