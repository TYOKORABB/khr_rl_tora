# 起き上がり用の別名 URDF（2026-10-14）

`python -m getup.tools.make_getup_urdf` → `../assets/khr3hv/urdf/khr3hv_symhip_getup.urdf`（リポジトリ外、非公開アセットの派生物なのでコミットしない）。

- 記録: `make_getup_urdf.json`（元の URDF・メッシュと出力のハッシュ、リンクごとの数値）。
