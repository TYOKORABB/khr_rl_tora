# getup-v10（候補 B・C を A1 の土台に 1 つずつ足す）— 計画と判定の基準（学習の前に固定、2026-11-05）

## 0. きっかけ

ユーザーの決定（11/4）:「候補の手法を優先度順に試してほしい。Dはやらなくて良い。」「あなたが提案したこの後の進め方で進めてください。しばらくWhisperは止めてもいいから最優先で学習を回して。」

提案した進め方: A の判定のあと、良い構成の上に B（静止の報酬、肩の姿勢）→ C（報酬の谷を埋める、止まった姿勢の追加、シード追加）の順に試す。成功の時間を広げる B3 は成功の定義を変えるので、本人に確かめてから。D は行わない。

## 1. 根拠

A の判定（`v9_results.md`）で A1 と canon が合格、sym が不合格。基準（`v9_plan.md` §3）で A1 を採った。F の最低は 95.2 % で並び、u0 ≥ 0.9 の平均が高い A1（91.1 %、canon は 88.7 %）。

A1 に残る失敗（段階 L3 の全状態に占める %、シード 1・2・3、`failure_modes_getup7-hardflip-s1_mirror.json`）:

| 型 | シード 1 | シード 2 | シード 3 | 平均 |
|---|---|---|---|---|
| 立つが静止しない | 3.62 | 5.52 | 3.34 | 4.16 |
| 姿勢の条件に入らない | 0.46 | 4.73 | 1.44 | 2.21 |
| 胸を向けられない | 0.00 | 0.00 | 0.00 | 0.00 |

参考: sym の立つが静止しない型は 0.51・1.21・0.42 %（平均 0.71）で、A1 と canon の 6 シードのどれより低い。この型が減らせることの根拠になる。ただし sym が減らす仕組みは調べていない。

## 2. 構成

土台は A1 と同じ: v7 の B（hard ＋ flipthr、L3、3000 イテレーション、シード 1・2・3）を、学習にスイッチを入れずに学習し、`--mirror` で検証する。候補は土台に 1 つだけ足す（`getup/train_getup10.py --base none --add <名前>`）。効果を切り分けるので、候補どうしは足し合わせない。

| 候補 | exp | 内容 | 狙う失敗 |
|---|---|---|---|
| B1 静止の報酬 | `getup10-still-s{1,2,3}` | 立っている間、角速度に連続の報酬を与える（重み 1、幅 0.5 rad/s） | 立つが静止しない |
| B2 肩の姿勢 | `getup10-pose-s{1,2,3}` | 立っている間、関節のずれが 0.2 rad を超えた分のペナルティ（重み −10、超えた分は 0.2 rad で切る）。全関節にかかる | 姿勢の条件に入らない |
| C1 谷を埋める | `getup10-fliplim-s{1,2,3}` | 胸が床を向くまで（u < 0.9）、可動域の端のペナルティの重みを 1/5 にする | 横倒しで止まる（スイッチなしで解けるか） |
| C2 止まった姿勢 | `getup10-replay-s{1,2,3}` | 胸を向けられないまま終わった体の姿勢を覚えて、段階 L3 のリセットの 15 % に使う。評価の状態は使わない | 横倒しで止まる（スイッチなしで解けるか） |

## 3. 判定の基準（学習の前に固定）

A1 との差で見る。候補ごとに 3 シードがそろうまで判定しない。「狙い」と「悪くしない」をすべて満たすと「改善あり」。

|---|---|

### 狙い

| 候補 | 条件 | A1 または B |
|---|---|---|
| B1 | 立つが静止しない型の平均 2.1 % 以下（半分） | 4.16 |
| B1 | 立つが静止しない型の最大のシード 2.8 % 以下（半分） | 5.52 |
| B1 | u0 ≥ 0.9 の成功の平均 93 % 以上（スイッチあり） | 91.1 |

- シードのばらつき: A1 の u0 ≥ 0.9 はシードの標準偏差が約 3.7 pt で、3 シードの平均の差の標準誤差は約 3 pt。93 % の条件だけでは偶然と区別できないので、失敗の型が半分になることを主な条件にした。「改善あり」でも、シードを足して確かめるまで言い切らない（§5）。
- 型の値は `failure_modes`（スイッチあり、評価用の L3 の全状態）から。
- 参考（判定には使わない）: L4 相当、L1、L0、主のバンクの胸が上、成功までの時間、昇格のイテレーション、スイッチなしの全指標（B1・B2）。
- 動画: 検証のたびに撮る。段階ごと（スイッチなしとあり）、脱力の横倒し（あり）、転んだ状態と胸が上（なしとあり）。

## 4. 事前の見立て（外れたらそれも記録する）

- B1: 立つが静止しない型は 4.2 → 1.5〜3 %、u0 ≥ 0.9 は 92〜95 %。改善ありになるかは五分五分。
- B2: 姿勢の条件に入らない型は 2.2 → 1〜2 %。立つのが遅れて、立つが静止しない型が増えるかもしれない。改善ありになる見込みは 4 割。
- C1: スイッチなしで止まるシードが減るかは不確か。8 条件の合格は 3 割。
- C2: 止まった姿勢の練習が増えるので C1 よりは直接効くと見るが、8 条件の合格は 3〜4 割。
- 1 シードは約 83 分（学習 54 分、検証 29 分）で、候補 1 つ約 4.3 時間、4 候補で約 17 時間。

## 8. 追加: sym に C1・C2 を足す（学習の前に固定、2026-11-05）

ユーザーの決定:「ｃ２の後にsymにｃ１とｃ２をたす構成も追加して自動でやっといてほしい。」

### 根拠

sym は シード 1 が全構成で最も高い（F 98.7 %、L4 相当 98.4 %、u0 ≥ 0.9 98.0 %）一方、シード 2・3 は左右どちらの横倒しでも止まる（F 0.87 %）。立つが静止しない型は 3 シードとも最少（0.42〜1.21 %）。止まるシードがなくなれば、スイッチなしで A1 を超える可能性がある。

### 構成

C1 と C2 を別々に足す構成と、両方足す構成の 3 つ。「C1 と C2 を足す」はどちらにも読めるので、両方を行う。

| 構成 | exp | 学習の引数 |
|---|---|---|
| sym ＋ C1 | `getup10-symfliplim-s{1,2,3}` | `--base sym --add fliplim` |
| sym ＋ C2 | `getup10-symreplay-s{1,2,3}` | `--base sym --add replay` |
| sym ＋ C1 ＋ C2 | `getup10-symboth-s{1,2,3}` | `--base sym --add fliplim replay` |

### 判定の基準

スイッチなしで `v9_plan.md` §3 の 8 条件をすべて満たすと合格。

| 条件 | sym |
|---|---|
| F の平均 85 % 以上 | 33.5 |
| F が 3 シードとも 70 % 以上 | 98.7、0.87、0.87 |
| L4 相当の平均 80 % 以上 | 64.3 |
| L3 の平均 80 % 以上 | 91.5 |
| L2 の平均 85 % 以上 | 97.3 |
| u0 ≥ 0.5 の脱力の平均 85 % 以上 | 98.4 |
| 脱力の横倒し M の平均 70 % 以上 | 56.7 |
| トルクが上限に張り付く時間が 3 シードとも 1 % 未満（L4 相当の最大） | 最大 0.437 |

- A1 との比較: 合格した構成と A1 を合わせて `v9_plan.md` §3 の規則で比べる（F の最低が最も高いもの、2 pt 以内で並べば u0 ≥ 0.9 の平均が高いもの）。
- 候補 B1・B2 が改善ありだった場合の最後の判断（§5）では、これらも合わせて比べる。
- 参考（判定には使わない）: 失敗の型、L1、L0、主のバンクの胸が上、トルクの 99 % 点、成功までの時間、昇格のイテレーション。
- 動画: 検証のたびに撮る。段階ごと、脱力の横倒し、転んだ状態、胸が上。

### 事前の見立て（外れたらそれも記録する）

sym はシード 1 だけが寝返りを覚えたので、3 シードとも 70 % を超えるのは難しい。合格の見込みは sym ＋ C1 が 3 割、sym ＋ C2 が 4 割、sym ＋ C1 ＋ C2 が 4 割。合格すれば、F の平均と u0 ≥ 0.9 は A1 より高くなると見る。

## 9. 追加: B1 にシード 4・5・6 を足す（学習の前に固定、2026-11-05）

ユーザーの決定:「B1のシードを追加しておいて。」

### 根拠

B1 はスイッチなしでも 3 シードとも止まらなかった（F 94.3、97.4、93.0 %）。これは §3 の判定の外の参考で、シード 1〜3 の結果を見てから立てた問いなので、シード 1〜3 だけでは確かめられない。同じ土台で v7 の B は 3 本中 1 本（F 28.0 %）、B2 は 3 本中 2 本（F 26.6、60.3 %）が F 70 % 未満。止まるシードが 3 分の 1〜2 分の 1 の割合で出るなら、3 本とも止まらないのは偶然でも 12〜30 % 起きる。

### 構成

`getup10-still-s{4,5,6}`（`--base none --add still`）。シードのほかは B1 と同じ。検証も B1 と同じ手順（`run_v10.sh` の候補 1 つ分）。

### 判定の基準

問いは「B1 の構成は、スイッチなしで使えるか」。スイッチなしの **6 シード**で `v9_plan.md` §3 の 8 条件を見る。

| 条件 | シード 1〜3 |
|---|---|
| F の平均 85 % 以上 | 94.9 |
| F が 6 シードとも 70 % 以上 | 94.3、97.4、93.0 |
| L4 相当の平均 80 % 以上 | 93.4 |
| L3 の平均 80 % 以上 | 92.2 |
| L2 の平均 85 % 以上 | 91.5 |
| u0 ≥ 0.5 の脱力の平均 85 % 以上 | 92.6 |
| 脱力の横倒し M の平均 70 % 以上 | 94.4 |
| トルクが上限に張り付く時間が 6 シードとも 1 % 未満（L4 相当の最大） | 最大 0.145 |

結果の読み方も先に決めておく。

| 結果 | 読み方 |
|---|---|
| 6 シードとも F 70 % 以上 | スイッチなしで使える構成の候補にする。止まるシードの割合が 3 分の 1〜2 分の 1 のままなら、偶然に起きるのは 1.6〜8.8 %。静止の報酬が原因かどうかは、§5 の C3 で土台の構成のシード 4・5・6 と比べるまで言わない |
| 1 本でも F 70 % 未満 | 静止の報酬で止まらなくなったとは言えない。スイッチなしの候補にしない |

- B1 の判定（§3、改善なし）はこの結果で変わらない。§3 の狙いは立つが静止しない型を減らすことで、問いが別。
- 最後に採る構成の判断（§5）では、合格していれば sym の追加（§8）と同じく `v9_plan.md` §3 の規則で比べる。
- 参考（判定には使わない）: スイッチありの全指標、失敗の型、L1、L0、トルクの 99 % 点。

### 事前の見立て（外れたらそれも記録する）

静止の報酬は立っている間だけ働くので、横倒しで止まるかどうかに効く理由は思い当たらない。シード 1 本が止まらない割合を 3 分の 2〜4 分の 3 と見て、シード 4・5・6 がすべて F 70 % 以上になる見込みは 3〜4 割。
