# getup-v7（L3 の弱点の改善）— 計画と判定の基準（学習の前に固定、2026-11-02）

## 0. きっかけ

ユーザーの決定（11/2）:「L4を始める前に、L3の分析でわかった弱点について、改善する手法をL3の状態で追加して、学習を行い検証をして欲しい。その結果を元に、L3で改善するか、L4に進むかを決めたい。」

## 1. 弱点（v6 の分析、`experiments/getup/eval/failure_modes_getup6-L3-s1.md`）

- 失敗の 54.6 % は胸を床へ向けられない型で、**脱力の横倒し**に集中する。横倒しの範囲（0 ≤ u0 < 0.5）の成功は、関節を保持して落とした状態で 87.7 %、脱力で落とした状態で 28.5 %（`eval_getup`）。
- 同じ状態が 3 シードとも失敗することが多く、シードの運ではない。
- 歩行中に転んだ状態も 100 % 脱力で、82.5 % は腕が閉じている。L4 で解きたい状態と同じ種類である。
- この種類の状態は、L3 の段階のリセットの約 10 % にしか当たらない。段階が上がる条件は、これを解かなくても満たせる。
- 失敗する体の最初の 2 秒のトルクは、最大の関節の平均で 47 %（成功は 55〜58 %）、エピソードの最大で 85〜86 %。上限（90 %）に張り付いていない。
  トルクのペナルティの閾値 0.60 が寝返りの力を抑えている疑いがある（0.60 はもともと立っている間の押し付けを止めるために入れた）。

## 2. 構成（2 通り × 3 シード、6 試行）

土台は getup-v6（dcthr ＋ L3、bank_v2、3000 イテレーション）。キュー `getup/jobs/queue_v7.txt`、全体の手順 `getup/jobs/run_v7.sh`。

| 構成 | v6 との差 |
|---|---|
| A: `getup7-hard-s{1,2,3}` | 苦手な状態を多く選ぶ。L3 の段階のリセットの半分を、学習用の脱力の横倒しの範囲（1,224 状態）から選ぶ。全リセットの約 40 %（v6 は約 10 %） |
| B: `getup7-hardflip-s{1,2,3}` | A ＋ 胸が床を向くまで（u < 0.7）トルクのペナルティの閾値を 0.60 → 0.85（v1〜v4 の値）。胸が向いた後は 0.60 のまま |

- 苦手な状態は、最初の状態の特徴（脱力・u0）だけで決める。評価用の状態や評価の結果は使わない。
- 変えるのは上の表だけで、トルクの上限（仕様の 90 %）、報酬のほかの項、L3 までの段階の上がり方は v6 と同じ。

## 3. 判定の基準（学習の前に固定）

主な指標 M は、**脱力の横倒しの範囲の成功率**（`eval_getup` の L3、ドメインランダム化あり、8 秒、評価用の 298 状態）。v6 は 28.5 %（シードごとに 28.5・29.2・27.9）。

| 判定 | 条件（すべて） |
|---|---|
| **改善あり** | M が 3 シードの平均で 50 % 以上、かつ 3 シードとも v6 の最高（29.2 %）を超える |
| 悪くしない 1 | L2 の成功が 3 シードの平均で 85 % 以上 |
| 悪くしない 2 | L3 の成功が 3 シードの平均で 80 % 以上 |
| 悪くしない 3 | u0 ≥ 0.5 の脱力の状態（669 状態）の成功が 3 シードの平均で 85 % 以上（実機に近い条件。v6 は 90.8 %） |
| 悪くしない 4 | L3 でトルクが上限に張り付く時間が 3 シードとも 1 % 未満 |

- A と B の両方が満たしたら A を採る（変更が少ない）。ただし B の M が A より 10 pt 以上高ければ B を採る。
- 50 % に理論の根拠はない。「脱力の横倒しの半分は起き上がれる」を、L4 に持ち込む手法として最低限の線に置いた。
- 3 シードがそろうまで判定しない。
- 判定を受けて L3 で改善を続けるか L4 に進むかは、ユーザーが決める。提案は次のとおり。
  - 改善あり: その手法を入れて L4 に進む。
  - 改善なし: 結果を見て、ほかの手法を試すか、L4 に進むかを相談する。
- 参考（判定には使わない）:
  - 腕が閉じた状態の成功、失敗の型の割合（`failure_modes`）
  - 歩行中に転んだ状態の全部の成功（L3 の範囲外がほとんどなので低いままとみる）
  - トルクの 99 % 点、立った後の揺れ（`hold_analysis`）
- 動画: 検証のたびに段階ごとに撮る（`eval_getup`）。加えて、脱力の横倒しだけの動画を撮る（`media/videos/getup/getup7-*_2999_limpside_L3.mp4`）。

## 4. 事前の見立て（外れたらそれも記録する）

- A: M は 40〜60 %。L2 の範囲の練習が減る（リセットの約 56 % → 約 31 %）ので、L2 は少し下がって 85〜90 %。
- B: M は A より高く 50〜70 %。トルクの 99 % 点と上限に張り付く時間は A より上がるが、1 % 未満に収まる。立った後は 0.60 のままなので、押し付けは戻らない。
