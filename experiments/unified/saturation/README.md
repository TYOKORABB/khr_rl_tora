## 2. 分かったこと

- **張りつきは弱いサーボのせいではない**。v31 を同じ比例ゲイン 7 で動かすと、目標角の 1 周期の変化は 0.06 を一度も超えず（99 % 点 0.04 rad）、ずれの上限 0.08 を超えるのは 11〜15 %（体重を支える肩・股関節・膝のピッチだけ）。
- 段階 0b の方策は、制限の 5〜6 倍（中央値 0.3 rad、99 % 点 1.5〜2 rad）の目標角の跳びを毎周期出し、制限がそれを削っている。行動はほぼ毎周期大きく振れている（|行動| の中央値 0.8）。歩行に関係しない関節まで張りつくので、力を出すための振り方ではなく、罰がないので出ている「ばたつき」と考えられる。
- 罰に見えていない理由: unified_env0 の行動の変化の罰 2 項は「送った目標角（制限のあと）」の変化で測るので、1 周期の変化は 0.06 で頭打ちになり、0.06 を超える跳びは罰に入らない。計画（`../stage0_plan.md` §2）では「行動の変化の罰は v31 と同じ物理量」としたが、制限のあとで測ったので、v31 の罰（行動そのものの変化）と同じではなかった。

### 6.1 なぜ張りつくのか（探索のゆらぎと速さの制限、`unified/tools/noise_vs_rate.py`）

ゆらぎつきで動かし、平均の目標角と前に送った目標角の差 μ_diff の大きさごとに、実際に送られた変化が平均の向きに進んだ平均を δ で割った値を出した（関節 × 周期）。

| μ_diff の大きさ [rad] | 段階 0b の割合 | 段階 0b の進み ÷ δ | 0c の割合 | 0c の進み ÷ δ | 決定的なら ÷ δ |
|---|---|---|---|---|---|
| 0〜0.03 | 2.9 % | 0.02 | 31.3 % | 0.04 | 0.17〜0.25 |
| 0.03〜0.06 | 3.2 % | 0.07 | 16.7 % | 0.20 | 0.74〜0.75 |
| 0.06〜0.12 | 7.7 % | 0.13 | 21.4 % | 0.24 | 1.00 |
| 0.12〜0.30 | 29.1 % | 0.25 | 22.5 % | 0.21 | 1.00 |
| 0.30〜0.60 | 26.1 % | 0.29 | 6.6 % | 0.21 | 1.00 |
| 0.60 以上 | 31.0 % | 0.32 | 1.5 % | 0.12 | 1.00 |

- std 0.5 のゆらぎは目標角で 0.5 × s rad（s は関節ごとに最大 1.2）で、速さの制限 δ = 0.06 rad よりずっと大きい。ゆらぎつきでは、平均を 0.06 rad 離しても送る目標角は δ の 1 割ほどしか狙った向きに進まず、0.3 rad 以上離してやっと 3 割になる。
- 学習はゆらぎつきで進むので、方策は送る目標角を操るために平均を大きく離すことを覚える（段階 0b の μ_diff は中央値 0.36 rad）。平均で動かすと、これがそのまま毎周期 δ いっぱいの跳び（張りつき）になる。
- 0c は平均の跳びを罰したので平均を大きく離せず（中央値 0.062 rad）、送る目標角を操れなくなって歩きを覚えなかった。0r は送った行動（ゆらぎを含む）で測ったので、ゆらぎそのものの罰で崩れた。
- 見立て: std 0.5 のままでは、どちらの罰でも張りつきは減らせない。目標角でのゆらぎ（0.5 × s）を δ くらいまで小さくする必要がある。ただし起き上がりは std 0.5 の固定で学習できた（getup-v11b〜v13）ので、段階 1 では起き上がりの探索との兼ね合いになる。
- 0c のシード 2 も比例ゲイン 7 で 0.001 m/s（速さの制限に当たる割合 5.6 %）で、その場に立ったまま。シード 3 は 0d に替えるため途中で止めた。
