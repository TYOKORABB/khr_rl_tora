# khr-quadruped29 (v29) 検証結果 — ❌ 棄却。前提だった「v28 の左右非対称」自体が誤診だった

- 記録日: 2026-10-05（学習 3 seed、17:02〜20:38。評価 20:38〜21:09）
- 設計: v28 に `leg_load_balance`(−1.0) と `hip_pos`(−1.0) を戻す（18 → 20 項目）
- 測定: 標準指標は 128 体・3 回反復、左右対称性は専用ツール（64 体・3 回反復）、いずれも 3 seed

## 1. ⚠️ まず訂正 — v28 の左右非対称は「拡大していなかった」

v29 を作った根拠は「後脚の左右非対称が v23 3° → v27 6〜8° → **v28 7.6〜10.1°** と拡大している」
だった。**これは誤りである。**

当時 v27 は **seed1・seed2 しか測っていなかった**（7.77 / 6.41）。
今回 **v27 の seed3 を含めて 3 seed で測り直した**ところ:

| 版 | 股関節 hip_pitch の左右差 [°]（seed 別） | 平均 |
|---|---|---|
| v27 | 7.72 / 6.14 / **10.69** | **8.18** |
| v28 | 8.65 / 9.75 / 7.46 | **8.62** |
| v29 | 10.42 / 14.66 / 7.49 | 10.85 |

**v27 と v28 の差は 0.44° しかなく、seed 内のばらつき（6.1〜10.7°）に完全に埋もれている。**
v27 seed3 が 10.69° と v28 のどの seed より大きい。

> **またしても不完全な seed 集合から傾向を読んだ。** 本研究で 4 回目の同型の誤りである
> （v24 の誤報、接地チャタリングの誤認、v28 非対称の誤診、そして今回）。
> **2 版を比べるときは、両方を同じ seed 数・同じツールで測ってからでないと何も言えない。**

## 3. 判定: ❌ v29 は棄却。**v28 を最良版として維持する**

| 項目 | 判定 |
|---|---|
| 主目的（左右対称性の改善） | ❌ 達成せず（8.62 → 10.85°、むしろ悪化方向） |
| 横ずれ率 | ❌ 2.01 → 4.35 %（v28 の 2 倍超） |
| 90%超の延べ時間 | ❌ 0.0000 → 0.0011 %（ノイズ床 2σ 内だが v28 より悪い） |
| トルク 99%点 | ❌ 58.51 → 59.63 % |
| 横移動 | ❌ 77 → 74 % |
| **後退** | ✅ **82 → 91 %**（唯一の明確な改善） |
| 前進・旋回・膝 ROM・足裏・転倒 | 同等 |

**`leg_load_balance` と `hip_pos` を戻しても左右対称性は改善せず、横ずれ・トルク余裕・横移動を
失っただけだった。** ablation の「この 2 項目は削除可」という判定は正しかったことになる。

## 4. では「後脚の動きが不自然」の正体は何か

v29 の結果を踏まえると、**左右非対称は原因ではない**（全版共通で 8〜11°、版間に差がない）。
残る候補は 1 つ。

**接地の分断**: 1 周期あたりの接地 ON/OFF 切替が **3.35〜3.70 回**（理想 2.0）。
**着地のたびに 1 回余計に跳ねている。** これも全版共通で、v27 3.35 / v28 3.53 / v29 3.70 と
版間の差は小さい。

> つまり**「不自然さ」は v28 固有の問題ではなく、v1 以来の全版が持つ性質**である可能性が高い。
> 対処するなら、着地の衝撃や接地の継続性を直接測って報酬化する新しい設計が要る
> （例: 接地の継続時間、着地時の鉛直速度）。これは v30 以降の課題。
