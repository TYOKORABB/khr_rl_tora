# トルクの上限のペナルティの閾値の感度分析（v31 基準）— 計画と判定の基準（学習の前に固定、2026-10-28）

ユーザーの決定（10/28）: 卒論 v6 への他の AI の改善案 B8「60 % と重み −12 の根拠。閾値を 50・70 % に振った感度分析を加えると強くなる」を実施する。

v31 のトルクの上限のペナルティ（`torque_limits`）は、最大トルクの 60 %（`torque_soft_ratio` 0.60）を超えた分の二乗に重み −12 を掛ける。
60 % と −12 は試行で決めた値である（v21 で 0.65 → 0.60、v31 で −8 → −12。`quad/khr_train_quad31.py` のコメントと開発日誌 v2）。
この 60 % が、少し動かすと結論（トルクを飽和させずに歩く）が崩れる値なのかを確かめる。重み −12 は変えない（1 か所だけ変える）。

## 1. 構成（6 本）

| 構成 | 学習 | シード | 比べる相手 |
|---|---|---|---|
| 閾値 50 % | `khr_train_quad31_tqsens.py --soft-ratio 0.50` | 1・2・3 | v31（シード 1〜6） |
| 閾値 70 % | `khr_train_quad31_tqsens.py --soft-ratio 0.70` | 1・2・3 | v31（シード 1〜6） |

- ほかは v31 と同じ（是正後の機体、4096 体、4000 イテレーション）。
- 基準の v31 は報酬の総点検で測ったシード 1〜3（`experiments/ablation_v31/results/khr-quadruped31-s{1,2,3}_*.json`）と、
  その追加で測ったシード 4〜6（`experiments/ablation_v31_ext/results/khr-quadruped31-s{4,5,6}_*.json`）。測定の道具は 10/17 から変わっていない（git の記録で確認）。

## 2. 測り方

報酬の総点検と同じ道具・引数（`quad/jobs/run_abl31.sh` の測定）: 前進・後退・左右旋回・左横移動・押し（各 128 体・3 回反復、関節の 0 点のずれあり／なし）、
対称性（64 体）、前進の動画（12 s、`media/videos/tqsens/`）。主な条件は関節の 0 点のずれあり（`with_offset`）。動画はユーザーの決まり「検証では毎回動画」のとおり全部撮る。

## 3. 判定の基準（学習の前に固定）

- 差: Δ = 変えた構成の 3 シードの平均 − 基準の v31 の 6 シードの平均。
- 比べる幅 σ: 次のうち最大のもの。
  (a) 是正後のノイズ床（`experiments/noise_floor_fixurdf.json`、v23 × 4 シード）の標準偏差、
  (b) 是正後の全版の再学習の v12〜v29 の 18 版で、版の中のシード間のばらつきをまとめた標準偏差（自由度 37、`results_json_fixurdf/` から計算）、
  (c) 基準の v31 の 6 シードの標準偏差、(d) 変えた構成の 3 シードの標準偏差。
  (b) を足したのは、v23 の 4 シードの σ が多くの版のばらつきより小さいと分かったため（2026-10-28 の確認。v6 の 6.4 節の 18 版中 13 版）。
- **差がある**: |Δ| が 2σ を超え、かつ 3 シードすべてが基準の平均の同じ側にある。
- 見る指標: トルクの 99 % 点・90 % 超の時間・トルクの平均、前進の速さ・横ずれ率・押しの転倒、後退・左横移動・左右旋回の追従率、膝の可動範囲、足上げ（前・後）。
- **安全の条件**（2σ とは別、シードごとの最悪値）: 個体差ありの前進で、どれか 1 シードでもトルクの最大値が 100 % に達した。参考として、ほかの 4 方向の最大値も並べる。
- 論文に書くこと（結果を見てから書き方を変えない）:
  - 50 % と 70 % のそれぞれについて、安全の条件に触れたシードの数と、差がある指標（向きと σ の倍率）。
  - どちらも安全の条件に触れなければ「閾値を 50〜70 % の範囲で変えても，最大トルクに達したシードはなかった」と書く。
  - 70 % で触れれば「60 % は飽和を防げる範囲の上の側にある」、50 % で触れれば（見立てでは起きにくい）その事実をそのまま書く。

## 4. 事前の見立て（外れたらそれも記録する）

- 50 %: ペナルティを受ける範囲が広がるので、99 % 点とトルクの平均が下がり、前進の速さと足上げが少し下がる。
- 70 %: 99 % 点が上がり（60 % 台の前半）、前進の速さと足上げが少し上がる。ペナルティを外した構成（3 シードとも 100 %）ほどではないが、
  v31 でも 6 シードの最大値は 87.5〜93.8 % あるので、どれかのシードで 100 % に達する可能性がある。
