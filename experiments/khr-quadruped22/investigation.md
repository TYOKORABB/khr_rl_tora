# khr-quadruped22 (v22) 事前調査記録 — 左右対称性を「正しい量」で是正し、前進速度を回復

- 記録日: 2026-08-11
- 位置づけ: v21 でトルク余裕と足裏接地は回復したが、**左右対称性は対策が裏目に出て悪化**し、
  前進速度も未達だった。原因を特定して作り直す。

## 1. 出発点: v21 の結果

| 項目 | 目標 | v21 | 判定 |
|---|---|---|---|
| ピーク\|τ\|（個体差あり） | 90%未満 | **82%** | ✅ |
| 後脚 足裏傾き | 10°以内 | **7.8°** | ✅ |
| 後退速度 | 0.25以上 | 0.260 | ✅ |
| **前進速度** | 0.25以上 | **0.223** | ❌ |
| **後脚 接地率 左右差** | 5pt以内 | **14.0 pt** | ❌ |

## 2. 診断: 「罰している量」と「直したい量」が一致していなかった

v21 では対称性のために `leg_load_balance` を **−1.0 → −2.0 と強めた。しかし接地率の左右差は
9.5 → 14.0 pt と悪化した**（対策が裏目）。

原因は明確で、この報酬は

```python
def _reward_leg_load_balance(self):
    return torch.square(self.leg_tau_ema_l - self.leg_tau_ema_r)   # ← 左右の「トルク」EMA差
```

**「左右後脚のトルク EMA の差」**を罰するものであり、**「接地時間(duty)の左右差」とは別の量**である。
トルクを均衡させても接地タイミングは揃わない。**測っている量が、直したい量ではなかった。**

### これは本研究で3例目の同型の誤り

| 版 | 誤り | 修正 |
|---|---|---|
| v13 | `feet_clearance` が**絶対高さ**を目標にしていた（前脚は立位で既に超過＝足上げを罰していた） | **接地基準からの相対クリアランス**へ |
| v16 | 膝の**絶対角度**を報酬化 → 目標角度で固定する報酬ハック | **swing−stance の差分**へ（v17） |
| **v21** | 対称性のために**トルク差**を罰していた | → **接地duty差**へ（本版） |

**設計則: 「望む結果そのもの」を測って報酬にする。代理量で済ませない。**

## 3. v22 の変更（3点）

| 目的 | 変更 |
|---|---|
| **左右対称性（本命）** | `_reward_contact_duty_balance` を**新設**・`"contact_duty_balance": -10.0`。後脚の**接地duty（接地している時間の割合）の EMA の左右差**を直接罰する（α=0.01 ＝ 約4歩容周期の平均、初期値0.5で中立） |
| 左右対称性 | `leg_load_balance` **−2.0 → −1.0 に戻す**（強めたら悪化したため） |
| **前進速度の回復** | `tracking_lin_vel` **5.0 → 6.0**。トルク罰は据え置いたまま速度側の誘因を強める |

### 重みの根拠
報酬スケールは init で `dt` が掛かるため、ログの「Mean episode rew_X」は概ね **raw × scale** に相当する。
v21 実測の左右差 14pt（=0.14）なら raw = 0.14² = 0.0196、`scale −10` で **約 −0.196**。
これは `drift`（−0.25〜−0.77）と同程度であり、旧 `leg_load_balance`（−0.0037〜−0.0175）より
**1桁強く効く**。弱すぎて無視されることはない見込み。

### 据え置き（v21 で目標達成のため触らない）
`torque_soft_ratio` 0.60 / `torque_limits` −8.0（ピーク82%）、`feet_orientation` −4.5（足裏7.8°）。

### 維持（v20/v19 の成果）
`lin_vel_x_range` [-0.3, 0.3]（②後退）、`_reward_drift` の vx 成分（③旋回）、
関節オフセットDR ±0.02rad（①個体差への頑健性）、`tracking_sigma` 0.08。

### 事前スモークテスト（学習前・num_envs=4）
- 新設・変更・据え置き・維持の各値を assert で確認（全27報酬のメソッド対応 OK、報酬 finite）。
- **新報酬の反応を検証**: 接地duty 左右差 0pt → 罰 **0.00000**、
  左右差 14pt（v21実測値）→ 罰 **0.01960**。対称なら罰ゼロで、差にのみ反応することを確認。
