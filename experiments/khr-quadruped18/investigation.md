# khr-quadruped18 (v18) 事前調査記録 — 足裏全面での接地＋膝ROMの適正化

- 位置づけ: v17 で膝の周期運動は達成したが代償が出たため、その回収。
  ユーザ要望「**足の裏全体をうまく使って、踵だけで歩くとかつま先だけで歩くことがないようにしたい**」。
  方針は [[project_roadmap]]。

**到達点（維持したいもの）**

**代償（v18 で戻したいもの）**

| 課題 | v16 | v17 |
|---|---|---|
| ① トルクのピーク | 0.869 Nm (63%) | **1.246 Nm (91%)** @ r_knee |
| ② 追従（前進/後退/左横/右横） | 75/69/62/65% | **62/49/48/48%** |
| ③ 後脚 足裏傾き（接地時平均） | 16.1° | **21.4°** |

③ は v15（足裏水平罰を接地時のみに変更）以降 13.5→16.1→21.4° と悪化が続いており、
**つま先だけ／踵だけで接地している**状態。ユーザ要望はまさにここ。

## 2. v18 の対策（環境 khr_quad_env15 / 学習 khr_train_quad18）

2点。①② と ③ をそれぞれ狙う。

| 変更 | 内容 | 狙い |
|---|---|---|
| `knee_swing_flexion` **3.0 → 1.8** | 膝の運動量を適度に戻す。ROM 56° は過剰（v8 の 22° 程度が目安） | ①トルクピーク ②追従 |
| **足裏全面接地の強化** | `feet_orientation` **-1.0 → -3.0**（罰の強化）＋ `feet_orientation_prelanding_phase = 0.85` を新設し、接地中に加えて **着地直前（遊脚終盤 15%）からも足裏水平を要求** | ③接地の質 |

### 「足裏全面」の測り方について
足裏傾きの指標はソール法線の水平成分 `‖v_xy‖²` であり、
**ピッチ（つま先/踵の浮き）とロール（内外の縁の浮き）の両方**を同時に捉える。
つまりユーザ要望「踵だけ／つま先だけで歩かない」は、この指標を下げることと等価。

### 着地直前から要求する理由
接地時のみ罰しても「**傾いたまま足を振り下ろし、接地の瞬間に斜めに着く**」挙動は防げない。
着地前から水平に構えさせることで、足裏全面での着地を誘導する。

据え置き: 差分ベースの膝報酬（目標 +0.25rad、EMA α=0.05）、脚別クリアランス目標
（前0.012/後0.02）、`base_height` -3.0、トルク安全策（torque_limits -5.0 / dof_pos_error -1.0）、
leg_load_balance、heading_drift、feet_air_time。

### 干渉リスク（監視項目）
着地直前に足裏水平を求めると**膝の屈曲を抑制しうる**（v15 の逆方向の変更にあたる）。ただし
(a) 膝報酬は 1.8 で継続、(b) 対象は周期の終盤 15% のみ、なので影響は限定的と見込む。
**学習後に膝 ROM が潰れていないかを必ず確認する。**

### 事前スモークテスト（学習前・num_envs=4）
- scale（feet_orientation -3.0 / knee_swing_flexion 1.8）、prelanding_phase 0.85 を反映。
- 全26報酬のメソッド対応 OK、報酬 finite。
- **着地直前マスクの実効性を検証**: 同一状態で 着地直前(phase 0.90) の罰 = 0.1130 /
  遊脚中盤(phase 0.70) = 0.0559。着地直前の方が対象が広いことを確認。

### v18 の合否指標（v17比）
- **足裏傾きの改善（主目的③）**: 21.4° → 低下（v14 の 11.0° 前後が目安）。
  左右とも下がり、つま先/踵だけの接地が解消していること。
- **トルクのピーク低下（主目的①）**: 1.246 Nm(91%) → 定格 80% 未満へ。飽和 duty は 0/22 を維持。
- **追従の回復（主目的②）**: 前進 62% → v16 水準（75%前後）へ。
- **膝 ROM が潰れていないこと（干渉チェック・必須）**: 56° から下がるのは想定内だが、
  v15 の 7° 台まで戻ってしまっては本末転倒。**20〜35° 程度**に収まるのが理想。
- 後脚クリアランス（0.016/0.015m）を大きく落とさないこと。接地滑りの低下。
- エピソード長・左右対称性が崩れないこと。
