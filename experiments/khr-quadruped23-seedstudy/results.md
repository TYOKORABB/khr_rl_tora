## 2. 判定 — v20〜v23 で追っていた差の多くは**ノイズだった**

| 議論していた差 | 実際の差 | ノイズ 2σ | 判定 |
|---|---|---|---|
| **膝 ROM**（v21 の 45〜47° は「過大」、v22/v23 の 27° は「理想」） | 約 18° | **19.7°** | ❌ **ノイズ**。同一設定でも seed で **21.6〜45.3°** と倍以上ばらつく |
| **ピークトルク**（v20/v23 の 93〜100% は「危険」、v21 の 82% は「安全」） | 約 16pt | **14.3pt** | ❌ **ほぼノイズ**。同一設定でも **78.3〜98.1%** の幅 |
| **接地率 左右差**（v22 の 2.2pt は「大成功」、v23 の 12.5pt は「悪化」） | 約 10pt | **8.5pt** | ❌ **実質ノイズ**。同一設定でも **0.9〜11.8pt** で、v22 も v23 もこの範囲に収まる |
| 横ずれ率（v22 の 13.9%） | 約 6pt | 3.8pt | 🟡 **v22 のみ有意の可能性**（seed 範囲 6.1〜10.9% の外側） |
| 前進速度（v19 の 0.249 vs v23 の 0.230） | 0.019 | 0.017 | 🟡 **境界**。v21/v22/v23 間の差はノイズ内 |

**⇒ v20 以降で私が下してきた「この版は良い／悪い」という判断の多くは、統計的根拠を欠いていた。**

## 3. 一方で、信頼できる結論も得られた

| 指標 | σ | 結論 |
|---|---|---|
| **90%超の時間** | **0.00**（全 seed・全条件） | **どの seed でもトルクが定格90%を超える時間はゼロ**。実機の熱的・脱調リスクは低い |
| トルク 平均 | 0.30〜0.33 | **18% 前後で極めて安定**。版・seed によらない |
| トルク 99%点 | 1.13〜1.88 | 57〜62% で安定 |
| 前進速度 | 0.006〜0.009 | 0.22〜0.23 m/s で安定 |

**トルク安全性は「ピーク」ではなく「平均・99%点・90%超の時間」で見れば極めて安定しており、
どの版でも実機投入に問題ない水準**である、というのが本 study の実用上の最大の収穫。

## 4. 今後への反映

1. **版の採否は「2σ を超える差」があるときのみ主張する**。それ未満は「区別できない」と記す。
2. **ピーク（最大値）を評価指標に使わない**。平均・分位点・閾値超過時間を用いる。
3. **ablation（`ResearchPlan.md` Phase 2）も複数 seed で行う**。1本での比較は結論を出せない。
   本 study の σ を基準に、必要な seed 数を見積もれる。
4. **実機での版選択**: シミュ指標の小差では決められないため、
   **候補（v19 / v21 / v23）を実機で直接比較する**のが妥当。
